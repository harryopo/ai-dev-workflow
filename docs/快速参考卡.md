# Skill 开发快速参考卡（官方规范版）

## 1. 目录结构

```
my-skill/
├── SKILL.md          # 必须
├── references/       # 可选——按需加载
├── assets/           # 可选——模板、图片
└── scripts/          # 可选——可执行脚本
```

---

## 2. 三层加载机制

| 层级 | 何时加载 | 上下文占用 |
|------|---------|-----------|
| 元数据 | 会话启动 | ~100 tokens/skill |
| 正文 | 被调用时 | 全文注入 |
| 目录资源 | 正文引用时 | 仅读取的文件 |

---

## 3. Frontmatter 核心字段

```yaml
---
name: my-skill                    # /slash-command 名称
description: |                    # 前 250 字符必须包含触发条件
  做什么 + 什么时候触发
context: fork                     # fork = 独立子 Agent
agent: general-purpose            # 子 Agent 类型
allowed-tools: Read Write Edit    # 免询问工具
disable-model-invocation: false   # true = 只能手动触发
user-invocable: true              # false = 用户不可见
paths: "*.md, src/**/*.ts"        # 限定文件范围
---
```

---

## 4. Description 写作公式

```
前 250 字符 = 做什么 + 触发词
```

**示例：**
```yaml
description: |
  代码审查工具。当用户提到"代码审查"、"review"、
  "检查代码"时触发。审查质量、安全性、性能。
```

**禁忌：**
- ❌ "这个 Skill 可以帮助你..."
- ❌ 模糊描述，无触发词
- ❌ 超过 250 字符才说重点

---

## 5. fork vs inline 选择

| 场景 | 选择 | 原因 |
|------|------|------|
| 独立任务 | fork | 不占主对话上下文 |
| 需要对话历史 | inline | fork 拿不到历史 |
| 复杂任务 | fork | 上下文生存策略 |
| 简单指令 | inline | 默认即可 |

**判断法则：** 指令自带全部信息用 fork，依赖对话上下文用 inline

---

## 6. 调用控制矩阵

| 配置 | 用户可调 | Claude 自动调 | description 在上下文 |
|------|---------|--------------|-------------------|
| 默认 | ✅ | ✅ | ✅ |
| disable-model-invocation: true | ✅ | ❌ | ❌ |
| user-invocable: false | ❌ | ✅ | ✅ |

---

## 7. 字符串替换变量

| 变量 | 说明 |
|------|------|
| `$ARGUMENTS` | 用户传入的所有参数 |
| `$0`, `$1`, `$2`... | 按索引访问参数 |
| `${CLAUDE_SKILL_DIR}` | SKILL.md 所在目录绝对路径 |
| `${CLAUDE_SESSION_ID}` | 当前会话 ID |

---

## 8. Shell 预处理

```markdown
当前分支：!`git branch --show-current`
未提交文件：!`git status --short | wc -l` 个
```

---

## 9. 最佳实践清单

- [ ] description 前 250 字符包含触发词
- [ ] 正文 ≤500 行
- [ ] 参考资料放 references/
- [ ] 用 ${CLAUDE_SKILL_DIR} 引用文件
- [ ] 复杂任务用 context: fork
- [ ] 隐形任务用 user-invocable: false

---

## 10. 常见错误速查

| 问题 | 解决 |
|------|------|
| Skill 未触发 | 检查 description 触发词 |
| 上下文爆炸 | 正文精简 + 用 fork |
| 无法自动调用 | disable-model-invocation: false |
| 用户看不到 | user-invocable: true |
| 路径错误 | 用 ${CLAUDE_SKILL_DIR} |

---

## 11. 存放位置

| 优先级 | 路径 | 范围 |
|--------|------|------|
| 1 | `~/.claude/skills/<name>/SKILL.md` | 用户全局 |
| 2 | `.claude/skills/<name>/SKILL.md` | 当前项目 |
