# 本地开发 → 云端部署：20 项差异与处置

> 用途：04 文档第 10 节的展开说明。部署前逐项确认，每项都要有「差异处置」，不能只写「注意」。
> 判定标准：本地能跑 ≠ 云端能跑；差异不是收尾工作，是部署的主体工作。

## 一、环境与依赖

### 1. 运行时版本

- 症状：本地 Python 3.12 / Node 22，云端默认 3.8 / 18，语法或依赖装不上。
- 检查：`python --version`、`node --version`，与云端镜像/构建配置比对。
- 处置：在项目里锁定版本（`.python-version`、`.nvmrc`、Dockerfile），云端显式指定。

### 2. 依赖锁定

- 症状：本地 `pip install` / `npm install` 得到新版本，云端构建结果不同。
- 检查：是否有锁文件（`requirements.txt` 精确版本、`package-lock.json`、`poetry.lock`）。
- 处置：提交锁文件；构建用 `npm ci` / `pip install -r` 而非浮动安装；禁止 `latest`。

### 3. 环境变量与密钥

- 症状：本地 `.env` 能读，云端没配；或密钥被提交到仓库。
- 检查：`git log -p` 搜 secret；对照 `.env.example` 与云端配置项。
- 处置：云端用平台密钥管理；本地 `.env` 进 `.gitignore`；泄露后立即轮换，不是删提交就完事。

### 4. 系统依赖与编译工具

- 症状：本地已装 gcc / ffmpeg / 中文字体，云端镜像没有，构建或运行失败。
- 检查：列出需要系统级依赖的包；在干净镜像里跑一次构建。
- 处置：写进 Dockerfile 或部署文档；能换纯 Python/纯 JS 实现就换。

### 5. 磁盘与内存

- 症状：本地 16GB 内存 + SSD，云端 512MB 实例，构建 OOM 或磁盘写满。
- 检查：记录构建峰值内存、数据目录大小、日志增长速度。
- 处置：限制并发与缓存；日志轮转；必要时升级实例或改离线构建。

## 二、网络与访问

### 6. 端口与防火墙

- 症状：本地 `localhost:3000` 可访问，云端安全组未放行，外部打不开。
- 检查：服务监听地址是 `0.0.0.0` 还是 `127.0.0.1`；云防火墙/安全组规则。
- 处置：监听 `0.0.0.0`；只放行必要端口；数据库端口不对公网开放。

### 7. 反向代理、HTTPS 与域名

- 症状：本地 HTTP 正常，云端需要 HTTPS；域名解析未生效；证书过期。
- 检查：`curl -I https://<域名>`；证书到期时间；代理转发头是否正确。
- 处置：用 Nginx/Caddy/平台托管；配置 `X-Forwarded-For/Proto`；证书自动续期。

### 8. CORS 与跨域

- 症状：本地前端后端同源，云端前后端分域，浏览器报 CORS。
- 检查：浏览器控制台错误；响应头 `Access-Control-Allow-Origin`。
- 处置：白名单具体域名，不用 `*` 配凭证；预检请求要放行。

### 9. DNS 与缓存

- 症状：改了配置但访问还是旧内容；CDN 缓存未刷新。
- 检查：`dig` / `nslookup`；响应头 `cache-control`、`age`。
- 处置：部署后刷新 CDN；静态资源加版本号；DNS TTL 提前调低。

## 三、文件与数据

### 10. 文件路径与大小写

- 症状：Windows 路径 `C:\data\file.txt` 在 Linux 不存在；`Data.json` 与 `data.json` 在 Linux 是两个文件。
- 检查：搜索绝对路径、反斜杠、大小写不一致的引用。
- 处置：统一用相对路径 + `pathlib` / `path.join`；文件名全小写；大小写敏感环境复跑一次。

### 11. 文件权限

- 症状：本地以管理员运行，云端以非 root 运行，写文件/建目录失败。
- 检查：服务运行用户；目录属主与权限；`umask`。
- 处置：数据目录显式授权；不要用 `chmod 777`；容器内用非 root 用户。

### 12. 持久化存储

- 症状：容器重启后上传的文件、SQLite 数据库消失。
- 检查：数据目录是否挂载卷；是否写在容器临时层。
- 处置：挂载持久卷；或用对象存储/托管数据库；备份策略单独配置。

### 13. 数据库迁移

- 症状：本地库结构新，云端旧；启动时报列不存在。
- 检查：迁移脚本是否随部署执行；版本表是否一致。
- 处置：部署前跑迁移；迁移脚本可重复执行；准备回滚脚本；先备份。

### 14. 时区与语言环境

- 症状：本地东八区，云端 UTC，定时任务差 8 小时；中文排序/编码异常。
- 检查：`date`、`locale`；数据库时区设置。
- 处置：统一存 UTC，展示层转本地时区；显式设置 `TZ`；文件编码统一 UTF-8。

## 四、运行与观测

### 15. 日志与轮转

- 症状：日志写在容器里，重启即丢；日志无限增长占满磁盘。
- 检查：日志输出到 stdout 还是文件；是否配置轮转。
- 处置：输出 stdout 由平台收集；文件日志配 `logrotate`；禁止记录敏感信息。

### 16. 健康检查

- 症状：进程还在但接口不通，平台仍认为健康。
- 检查：是否有 `/health` 端点；检查是否覆盖数据库/依赖。
- 处置：加健康检查；区分存活与就绪；失败自动重启或告警。

### 17. 资源限制与并发

- 症状：本地单用户，云端多人访问，连接池耗尽、内存上涨。
- 检查：数据库连接数、线程/协程上限、队列长度。
- 处置：设置连接池上限；加限流；压测一条核心路径。

### 18. 后台任务与定时任务

- 症状：本地手动跑脚本，云端没有 cron；多实例重复执行。
- 检查：任务如何触发；是否有多实例并发。
- 处置：用平台定时任务/队列；加分布式锁或幂等键；记录每次执行结果。

## 五、交付与兜底

### 19. 备份与回滚

- 症状：升级失败，旧版本没留，数据被迁移改坏。
- 检查：发布前是否备份；旧镜像/旧包是否保留；回滚步骤是否演练。
- 处置：发布前备份数据库与配置；保留上一版产物；回滚命令写进 04；回滚后验证核心路径。

### 20. 费用与告警

- 症状：忘记关测试实例、API 超额、流量被打爆，账单超预算。
- 检查：云资源清单、API 配额、账单告警。
- 处置：设预算告警；设 API 限额与熔断；测试资源用完即停；每月核对账单。

## 六、个人项目额外高频坑

| 坑 | 表现 | 处置 |
|---|---|---|
| 范围蔓延 | 功能越做越多，永远上不了线 | 01 的非目标写死；新想法进 P2，不插队 |
| 过度设计 | 为 10 个用户搭微服务 | 单机 + 单数据库起步；有数据再拆 |
| 无测试 | 每次改动都怕 | 只测核心路径与验收判据，不追求覆盖率 |
| 密钥进 GitHub | 仓库公开后密钥泄露 | 提交前秘密扫描；泄露立即轮换 |
| 依赖供应链 | 随手装冷门包，含恶意代码 | 只用以维护的包；锁版本；看许可证 |
| 无备份 | 误删数据库/文件 | 自动备份 + 恢复演练一次 |
| 免费额度陷阱 | 免费层休眠/限流/删数据 | 上线前确认限制；关键服务付费 |
| 域名与备案 | 国内服务器域名未备案被拦 | 提前确认备案要求；或选境外/本地工具形态 |
| API 限流 | 调用超限，功能间歇失败 | 加重试 + 退避 + 本地缓存 + 额度告警 |
| 无监控 | 出问题靠用户告诉 | 至少加健康检查 + 错误日志 + 一条告警 |

## 七、部署前 10 分钟自检

1. 在干净目录按 04 从零跑一遍。
2. 用与云端相同的运行时版本跑一遍。
3. 检查所有环境变量在云端已配置。
4. 检查密钥没有硬编码、没有进仓库。
5. 检查数据库迁移能在空库与旧库各跑一次。
6. 检查健康检查端点可用。
7. 检查日志能定位到一次完整请求。
8. 检查备份与回滚步骤能执行。
9. 检查费用告警与 API 限额已设置。
10. 记录本次部署的版本号与时间，写进 05。
