## 9. 常见故障排查

| 现象 | 可能原因 | 检查命令 | 处置 |
|---|---|---|---|
| 启动报端口占用 | 旧进程未退出 | | 结束进程或换端口 |
| 依赖安装失败 | 网络/镜像/版本冲突 | | 换镜像、锁版本 |
| 路径找不到 | 工作目录不对/路径大小写 | | 用绝对路径核对 |
| 中文乱码 | 编码未设 UTF-8 | | 设置编码 |
| 连接数据库失败 | 服务未启动/连接串错误 | | 检查连接串与防火墙 |
