# 平台选择指南

## 平台对比速查表

| 维度 | 小程序 | 桌面应用 | 网页应用 | 手机App | Skill |
|------|--------|---------|---------|---------|-------|
| **用户获取** | 微信生态内搜索 | 需要下载安装 | 搜索引擎/链接 | 应用商店 | Agent市场 |
| **开发成本** | 中等 | 低 | 中等 | 较高 | 低 |
| **上架难度** | 需审核 | 无审核 | 无审核 | 需审核 | 需审核 |
| **离线使用** | 部分支持 | 完全支持 | 部分支持 | 部分支持 | 不支持 |
| **推送通知** | 模板消息 | 系统通知 | 浏览器推送 | 原生推送 | 不支持 |
| **跨平台** | 微信/支付宝/抖音 | Windows/Mac/Linux | 全平台 | iOS + Android | 多Agent |
| **适合场景** | 轻量级工具、营销 | 数据管理、生产力 | SaaS、展示、管理后台 | 社交、内容、电商 | AI能力扩展 |

## 选择决策树

```
你的产品需要什么？
│
├─ 需要微信生态能力（支付、分享、扫码）→ 小程序
│
├─ 需要本地文件操作/离线使用 → 桌面应用
│
├─ 需要多端访问/SEO/快速迭代 → 网页应用
│
├─ 需要原生体验/推送通知/相机等 → 手机App
│
└─ 扩展AI Agent能力 → Skill
```

## 各平台技术栈详解

### 小程序（Taro）
- **框架**：Taro 3.x + React + TypeScript
- **优势**：一次开发，多端运行（微信/支付宝/抖音/H5）
- **限制**：包大小限制（微信2MB），API受限于平台
- **发布**：需要各平台开发者账号

### 桌面应用（PySide6）
- **框架**：Python 3.10+ + PySide6 + SQLite
- **优势**：开发快、AI擅长Python、功能强大
- **限制**：仅桌面端、打包体积较大
- **发布**：直接分发exe

### 网页应用（Next.js）
- **框架**：Next.js 14+ + React + TypeScript + Tailwind CSS
- **优势**：跨平台、SEO友好、部署简单
- **限制**：需要服务器、无原生能力
- **发布**：Vercel/服务器部署

### 手机App（React Native）
- **框架**：React Native + Expo + TypeScript
- **优势**：一套代码iOS+Android、接近原生体验
- **限制**：需要Mac开发iOS、调试复杂
- **发布**：App Store / Google Play

## 开发效率排名

1. **桌面应用** - AI最擅长Python，开发最快
2. **网页应用** - Next.js生态成熟，模板丰富
3. **小程序** - Taro简化了多端开发
4. **手机App** - 环境配置复杂，调试周期长
5. **Skill** - 最轻量，但需要理解SKILL.md规范
