# 微信小程序开发全流程指南

> 来源：第二轮调研 R1
> 用途：阶段 5 编码实施时的小程序开发参考

## 1. 各小程序平台对比

| 平台 | 月活用户 | 用户画像 | 适合业务 | 开放能力差异 |
|------|---------|---------|---------|------------|
| **微信** | ~13 亿 | 全年龄、下沉渗透强 | 社交裂变、电商、工具、本地服务 | 生态最完整；支付成熟；社交分享最强 |
| **支付宝** | ~9 亿 | 商业/支付场景、一二线 | 生活缴费、政务、出行、商业服务 | 信任背书强；芝麻信用；支付转化高 |
| **抖音** | ~7 亿 | 年轻化、娱乐消费 | 内容营销、直播电商、本地生活 | 短视频/直播挂载；流量爆发强 |
| **百度** | ~6 亿 | 搜索场景、信息获取 | 内容站、知识付费、本地服务 | 搜索流量入口；SEO 加成 |
| **快手** | ~7 亿 | 下沉市场、社交信任高 | 直播电商、本地生活、社交 | 老铁信任经济；私域转化高 |

> **首选微信**（生态最全、文档最完善、门槛最低），后续可借 uni-app/Taro 复用代码。

## 2. 从 0 到上线操作清单

### 前置准备
- [ ] 注册账号：[mp.weixin.qq.com](https://mp.weixin.qq.com/)
  - 个人主体：无法使用支付、类目受限
  - 企业主体：需营业执照；可开通微信支付、广告主
- [ ] 获取 **AppID**（注册后在「开发设置」查看）
- [ ] 选择服务类目（部分需资质：医疗/金融/电商/教育）
- [ ] 配置服务器域名（HTTPS + ICP 备案）

### 开发环境
- [ ] 下载**微信开发者工具**：[开发者工具下载](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
  - 支持 Win/Mac/Linux
  - 推荐使用稳定版（Stable Build）

### 本地开发
- [ ] 工具中「新建项目」→ 填 AppID → 选择模板（JS / TS / 云开发）
- [ ] 目录结构：
  ```
  pages/        # 页面
  components/   # 组件
  app.json      # 全局配置
  app.js        # 入口
  utils/        # 工具
  ```
- [ ] 编译热更新：`Ctrl/Cmd + B`
- [ ] 调试：内置 Console / Network / Storage / Wxml 面板

### 预览方式
| 方式 | 说明 |
|------|------|
| 开发者工具预览 | 模拟器内即编即看 |
| **真机预览二维码** | 扫码在微信内打开（开发版） |
| **体验版二维码** | 上传代码版本并设为体验版，指定体验成员可访问 |
| **CI/CLI 自动化预览** | [miniprogram-ci](https://developers.weixin.qq.com/miniprogram/dev/devtools/ci.html) 支持命令行上传/预览 |

### 上传发布
- [ ] 开发者工具「上传」→ 生成版本号
- [ ] 进入「版本管理」
- [ ] 提交审核（人工 + 机审）：[审核规则](https://developers.weixin.qq.com/miniprogram/product/review.html)
- [ ] 审核通过后「发布」上线
- **审核周期**：一般 1-7 天，常见 1-2 天

## 3. 技术栈选型

| 框架 | 学习成本 | 性能 | 生态 | 多端能力 | 推荐场景 |
|------|---------|------|------|---------|---------|
| **原生** | 低 | 最优 | 微信官方 | 仅微信 | 纯微信项目、追求极致性能 |
| **Taro**（React） | 中 | 良好 | 活跃（京东） | 微信/支付宝/H5/RN | React 技术栈、多端 |
| **uni-app**（Vue） | 中 | 良好 | 最活跃（DCloud） | 全端覆盖最广 | Vue 技术栈、快速多端 |
| mpvue | 中 | 一般 | 维护趋缓 | 主要微信 | 历史项目（不推荐新项目） |
| WePY | 中 | 良好 | 更新慢 | 主要微信 | 历史项目（不推荐） |

> **结论**：单端用原生，多端用 uni-app（Vue）或 Taro（React）

## 4. 后端方案

| 方案 | 免费额度 | 成本 | 锁定风险 | 适合场景 |
|------|---------|------|---------|---------|
| **微信云开发（CloudBase）** | CDN 1GB、数据库 0.5GB、云函数 4万次/月 | 低门槛按量付费 | 高（绑定微信） | 轻量应用、个人/小团队 |
| **自建后端** | 无免费 | 服务器几十元/月起 | 低 | 复杂业务、数据自主 |
| **Supabase / Firebase** | Firebase 较慷慨；Supabase 500MB | 海外服务国内慢 | 中 | 海外业务（国内不推荐） |

> **个人/轻量用云开发**；**企业或数据合适用自建后端**

## 5. 关键坑与限制

### 包体限制
- 主包 **≤ 2MB**
- 总包（含分包）**≤ 20MB**（部分企业 30MB）
- **解决**：分包加载、分包预下载、静态资源放 CDN

### 虚拟支付
- iOS 内虚拟商品**禁止微信支付**（必须走苹果 IAP）
- 安卓可走微信支付
- 实物商品/线下到店不受限

### 类目资质
- 医疗、金融、教育、政务、社交、电商需对应资质
- 个人主体类目有限

### 审核被拒常见原因
- 诱导分享/关注
- 页面空白/功能不全
- 未做隐私协议声明
- 类目与内容不符
- 仿冒品牌

### 性能优化
- 减少 setData 频率和数据量
- 图片懒加载、WebP、CDN 压缩
- 分包、按需注入（`lazyCodeLoading: requiredComponents`）
- 单页 < 1000 个 WXML 节点
- 长列表用虚拟列表

## 6. 成本与时间估算

| 项目 | 个人 MVP | 企业小程序（中等） |
|------|---------|------------------|
| 注册认证 | 个人免费 | 企业 300 元/年 |
| 微信支付 | 个人不可 | 交易费率约 0.6% |
| 开发人天 | 3-10 天 | 20-60 天 |
| 云开发/服务器 | 免费 ~10 元/月 | 100-500 元/月 |
| 域名+SSL | ~50 元/年 + 免费 SSL | 同左 + 高配数百元 |
| 审核周期 | 首次 1-7 天 | 同左 |
| **年度总成本** | **~50-500 元** | **~1500-8000 元** |
