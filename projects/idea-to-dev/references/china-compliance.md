# 国内合规清单

> 来源：调研报告 §四
> 用途：阶段 2 平台推荐时自动叠加的国内合规检查

## 8 项关键合规要求

### 1. ICP 备案（Web 站点）

- **适用**：Web 站点托管在国内服务器/域名
- **流程**：通过云服务商（阿里云/腾讯云）提交备案
- **所需材料**：身份证、域名证书、服务器实例、备案核验单、幕布拍照
- **周期**：约 7-20 个工作日（通常 1-3 周）
- **规避方案**：托管海外（Vercel/Cloudflare，牺牲国内访问速度）或用小程序/客户端形态绕开

### 2. 软著与商店资质（App）

- **软件著作权（软著）**：App 上架需软著登记
  - 申请：中国版权保护中心
  - 周期：正常 30 个工作日，加急 3-5 天
  - 费用：正常免费，加急几百元
- **应用商店资质**：金融/医疗/资讯/教育类有额外资质要求

### 3. 小程序类目资质

- **微信小程序**：金融、医疗、资讯、社交、电商等类目要求主体资质与牌照
- **个人主体**：功能受限（不可做电商、社交、医疗等）
- **企业主体**：需营业执照；可开通微信支付、广告主

### 4. 虚拟支付

- **iOS 端**：虚拟商品走 Apple IAP（30% 抽成）
- **微信小程序 iOS 端**：虚拟支付长期受限（博弈中）
- **实物商品/线下到店**：不受限，可走微信支付

### 5. 数据合规

- **《个人信息保护法》**：最小必要、知情同意、跨境传输评估
- **《数据安全法》**：数据分级分类、安全保护义务
- **GDPR**：面向欧洲用户的产品强制
- **要求**：隐私政策、用户协议、数据加密、审计日志

### 6. 苹果 ATT 与隐私清单

- **ATT（App Tracking Transparency）**：iOS 跟踪需用户授权弹窗
- **PrivacyInfo.framework**：2024 春起强制（SDK 与 App 均需）
  - Privacy Tracking Domains
  - Collected Data Types
  - Tracking Enabled

### 7. 生成式 AI 服务备案

- **适用**：直接面向 C 端的大模型应用
- **法规**：《生成式人工智能服务管理暂行办法》
- **要求**：需用已备案模型（DeepSeek/通义/智谱/文心等）
- **OpenAI/Anthropic 直连**：存在合规与网络问题，需代理或国内替代

### 8. 网络可达性

- **Vercel/Cloudflare/GitHub**：国内访问不稳定
- **OpenAI/Anthropic API**：直连受限
- **应对**：
  - 国内合规模型（DeepSeek/通义/智谱/文心）
  - 国内云服务商（腾讯云/阿里云）
  - 具备资质的 API 网关

## 合规检查流程（嵌入阶段 2）

```
平台推荐确定后：
1. 查"平台 × 合规对照表"，列出适用项
2. 逐项检查：
   - 是否已满足？
   - 需要什么前置准备？
   - 预计周期与成本？
3. 在方案书中单设"合规约束"章节
4. 如有硬性合规阻塞 → 标红警告，建议调整方案
```

## 常见合规踩坑

| 坑 | 后果 | 规避 |
|----|------|------|
| 未备案用国内服务器 | 网站被关停 | 先备案或用海外服务器 |
| 小程序个人主体做电商 | 审核被拒 | 注册企业主体 |
| iOS App 未做隐私清单 | 审核被拒 | 补 PrivacyInfo.framework |
| 直接调用 OpenAI API | 合规风险 | 用国内备案模型 |
| 未做 ATT 弹窗 | 审核被拒 | 实现 App Tracking Transparency |
| 收集数据无隐私政策 | 下架 | 上线前必备隐私政策+用户协议 |
