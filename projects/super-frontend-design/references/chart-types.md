# 25 图表类型参考手册

> 每个图表类型包含名称、最佳用途、使用场景、推荐库、数据格式示例和设计注意事项。
> 用于快速选择合适的数据可视化方案。

---

## 1. 折线图（Line Chart）
- **最佳用途**: 展示数据随时间的变化趋势
- **使用场景**: 股票走势、用户增长、温度变化、销售趋势、KPI监控
- **推荐库**: 
  - React: Recharts, Nivo, Victory
  - Vue: Vue-ECharts, Chart.js (vue-chartjs)
  - 原生: Chart.js, D3.js, ECharts
- **数据格式示例**:
```json
[
  { "date": "2024-01", "value": 120 },
  { "date": "2024-02", "value": 150 },
  { "date": "2024-03", "value": 180 }
]
```
- **设计注意事项**: 
  - X轴通常为时间维度，间距等比
  - 多条线时使用对比色，最多5条
  - 数据点密集时可隐藏点标记
  - 悬停显示具体数值（tooltip）
  - Y轴从0开始避免误导（除非有特殊需求）

## 2. 面积图（Area Chart）
- **最佳用途**: 展示数据随时间变化的趋势和累计量
- **使用场景**: 流量来源占比、收入构成、资源使用量、市场份额变化
- **推荐库**: 
  - React: Recharts, Nivo
  - Vue: Vue-ECharts
  - 原生: Chart.js, ECharts, D3.js
- **数据格式示例**:
```json
[
  { "date": "2024-01", "organic": 400, "paid": 240, "social": 180 },
  { "date": "2024-02", "organic": 450, "paid": 280, "social": 200 }
]
```
- **设计注意事项**: 
  - 堆叠面积图注意透明度避免遮挡
  - 使用半透明填充（opacity: 0.3-0.6）
  - 层数不超过5层
  - 堆叠顺序：最大值在底部
  - 颜色选择需考虑叠加后的视觉效果

## 3. 柱状图（Bar Chart）
- **最佳用途**: 比较不同类别的数值大小
- **使用场景**: 月度销售对比、部门业绩、产品评分、城市人口
- **推荐库**: 
  - React: Recharts, Nivo, Victory
  - Vue: Vue-ECharts, vue-chartjs
  - 原生: Chart.js, ECharts, D3.js
- **数据格式示例**:
```json
[
  { "category": "产品A", "value": 450 },
  { "category": "产品B", "value": 320 },
  { "category": "产品C", "value": 280 }
]
```
- **设计注意事项**: 
  - Y轴从0开始，避免视觉误导
  - 柱宽与间距比例约 1:1 到 2:1
  - 类别数超过12个考虑水平柱状图
  - 分组柱状图最多4组
  - 数值标签放在柱顶或柱内

## 4. 水平柱状图（Horizontal Bar Chart）
- **最佳用途**: 比较长标签的类别数值
- **使用场景**: 排行榜、技能评分、满意度调查、国家对比
- **推荐库**: 
  - React: Recharts, Nivo
  - Vue: Vue-ECharts
  - 原生: Chart.js, ECharts
- **数据格式示例**:
```json
[
  { "name": "JavaScript", "popularity": 65 },
  { "name": "Python", "popularity": 48 },
  { "name": "TypeScript", "popularity": 35 }
]
```
- **设计注意事项**: 
  - 按数值大小排序更直观
  - 标签左对齐，数值右对齐
  - 适合展示排名/排行
  - 长标签不会重叠

## 5. 堆叠柱状图（Stacked Bar Chart）
- **最佳用途**: 展示各类别的构成和总量
- **使用场景**: 收入构成、预算分配、流量来源、人口结构
- **推荐库**: 
  - React: Recharts, Nivo
  - Vue: Vue-ECharts
  - 原生: Chart.js, ECharts
- **数据格式示例**:
```json
[
  { "month": "1月", "产品A": 120, "产品B": 80, "产品C": 60 },
  { "month": "2月", "产品A": 150, "产品B": 90, "产品C": 70 }
]
```
- **设计注意事项**: 
  - 堆叠层数不超过5层
  - 最稳定的类别放底部
  - 使用对比色区分各层
  - 悬停显示各层具体数值
  - 考虑100%堆叠柱状图展示占比

## 6. 饼图（Pie Chart）
- **最佳用途**: 展示各部分占整体的比例
- **使用场景**: 市场份额、预算分配、流量来源、人口构成
- **推荐库**: 
  - React: Recharts, Nivo, Victory
  - Vue: Vue-ECharts, vue-chartjs
  - 原生: Chart.js, ECharts, D3.js
- **数据格式示例**:
```json
[
  { "name": "直接访问", "value": 335 },
  { "name": "搜索引擎", "value": 580 },
  { "name": "社交媒体", "value": 284 }
]
```
- **设计注意事项**: 
  - 分类不超过7个，超过则合并为"其他"
  - 最大的扇区从12点方向开始
  - 避免使用3D饼图（视觉失真）
  - 考虑用环形图替代（更现代）
  - 直接标注百分比，减少图例依赖

## 7. 环形图（Donut Chart）
- **最佳用途**: 展示占比关系，中心可放汇总数据
- **使用场景**: KPI达成率、任务完成度、资源分配、目标进度
- **推荐库**: 
  - React: Recharts, Nivo
  - Vue: Vue-ECharts
  - 原生: Chart.js, ECharts
- **数据格式示例**:
```json
[
  { "name": "已完成", "value": 75 },
  { "name": "进行中", "value": 15 },
  { "name": "未开始", "value": 10 }
]
```
- **设计注意事项**: 
  - 中心区域显示汇总数据（总数/百分比）
  - 环宽建议为半径的 30-50%
  - 分类不超过7个
  - 悬停时扇区微微外扩
  - 适合仪表盘场景

## 8. 散点图（Scatter Plot）
- **最佳用途**: 展示两个变量之间的相关关系
- **使用场景**: 身高vs体重、广告投入vs销售额、温度vs用电量
- **推荐库**: 
  - React: Recharts, Nivo, Victory
  - Vue: Vue-ECharts
  - 原生: Chart.js, ECharts, D3.js
- **数据格式示例**:
```json
[
  { "x": 160, "y": 55, "group": "A" },
  { "x": 175, "y": 72, "group": "B" },
  { "x": 168, "y": 63, "group": "A" }
]
```
- **设计注意事项**: 
  - 数据点过多时使用透明度避免重叠
  - 可添加趋势线辅助判断相关性
  - 不同组使用不同颜色/形状
  - 悬停显示具体坐标值
  - 考虑气泡图作为三维散点图

## 9. 气泡图（Bubble Chart）
- **最佳用途**: 展示三个维度的数据关系
- **使用场景**: GDP/人口/面积、产品收益/风险/投资额、市场分析
- **推荐库**: 
  - React: Recharts, Nivo
  - Vue: Vue-ECharts
  - 原生: ECharts, D3.js
- **数据格式示例**:
```json
[
  { "x": 50, "y": 80, "size": 30, "label": "产品A" },
  { "x": 70, "y": 60, "size": 45, "label": "产品B" }
]
```
- **设计注意事项**: 
  - 气泡面积（非半径）映射数值
  - 气泡透明度 0.5-0.7 避免遮挡
  - 提供图例说明气泡大小含义
  - 悬停显示三个维度的数值
  - 气泡数量控制在 20-30 个以内

## 10. 雷达图（Radar Chart）
- **最佳用途**: 多维度对比分析
- **使用场景**: 能力评估、产品对比、性能分析、用户画像
- **推荐库**: 
  - React: Recharts, Nivo
  - Vue: Vue-ECharts
  - 原生: Chart.js, ECharts
- **数据格式示例**:
```json
[
  { "dimension": "速度", "productA": 85, "productB": 70 },
  { "dimension": "稳定性", "productA": 90, "productB": 80 },
  { "dimension": "价格", "productA": 60, "productB": 85 }
]
```
- **设计注意事项**: 
  - 维度数 5-8 个最佳
  - 对比对象不超过3个
  - 使用半透明填充
  - 维度标签放在外侧
  - 数值范围统一（0-100）

## 11. 热力图（Heatmap）
- **最佳用途**: 展示二维数据的密度/强度分布
- **使用场景**: 用户行为分析、日历活跃度、地理分布、相关性矩阵
- **推荐库**: 
  - React: Nivo, React-Vis
  - Vue: Vue-ECharts
  - 原生: ECharts, D3.js
- **数据格式示例**:
```json
[
  { "x": "周一", "y": "9:00", "value": 85 },
  { "x": "周一", "y": "10:00", "value": 92 },
  { "x": "周二", "y": "9:00", "value": 45 }
]
```
- **设计注意事项**: 
  - 使用连续色阶（如白→蓝→红）
  - 提供色阶图例
  - 数值直接标注在单元格内（如果空间允许）
  - 色盲友好的色阶选择
  - 空值使用灰色区分

## 12. 树状图（Treemap）
- **最佳用途**: 展示层级数据的占比关系
- **使用场景**: 文件系统大小、市场份额层级、预算层级、投资组合
- **推荐库**: 
  - React: Nivo, Recharts
  - Vue: Vue-ECharts
  - 原生: ECharts, D3.js
- **数据格式示例**:
```json
{
  "name": "总预算",
  "children": [
    { "name": "研发", "value": 400, "children": [
      { "name": "前端", "value": 150 },
      { "name": "后端", "value": 250 }
    ]},
    { "name": "市场", "value": 300 }
  ]
}
```
- **设计注意事项**: 
  - 使用颜色区分类别，面积表示数值
  - 标签放在矩形内部
  - 层级不超过3层
  - 小矩形可隐藏标签，悬停显示
  - 支持下钻交互

## 13. 桑基图（Sankey Diagram）
- **最佳用途**: 展示数据的流动和转化关系
- **使用场景**: 用户转化漏斗、能源流向、资金流向、流量来源去向
- **推荐库**: 
  - React: Nivo
  - Vue: Vue-ECharts
  - 原生: ECharts, D3.js (d3-sankey)
- **数据格式示例**:
```json
{
  "nodes": [
    { "name": "访问" }, { "name": "注册" }, { "name": "购买" }
  ],
  "links": [
    { "source": "访问", "target": "注册", "value": 500 },
    { "source": "注册", "target": "购买", "value": 200 }
  ]
}
```
- **设计注意事项**: 
  - 流向从左到右或从上到下
  - 流量宽度与数值成正比
  - 使用渐变色连接源和目标
  - 悬停高亮相关路径
  - 节点标签清晰可读

## 14. 漏斗图（Funnel Chart）
- **最佳用途**: 展示流程中的转化率和流失
- **使用场景**: 销售漏斗、注册转化、招聘流程、用户旅程
- **推荐库**: 
  - React: Recharts, Nivo
  - Vue: Vue-ECharts
  - 原生: ECharts
- **数据格式示例**:
```json
[
  { "stage": "访问", "value": 10000 },
  { "stage": "注册", "value": 5000 },
  { "stage": "激活", "value": 2500 },
  { "stage": "付费", "value": 800 }
]
```
- **设计注意事项**: 
  - 每层显示绝对值和转化率
  - 使用渐变色从宽到窄
  - 层数 4-7 层最佳
  - 标注层间转化率
  - 考虑水平方向展示

## 15. 甘特图（Gantt Chart）
- **最佳用途**: 展示项目时间线和任务进度
- **使用场景**: 项目管理、开发排期、活动策划、资源分配
- **推荐库**: 
  - React: @syncfusion/ej2-react-gantt, frappe-gantt
  - Vue: dhtmlxGantt
  - 原生: D3.js, Frappe Gantt
- **数据格式示例**:
```json
[
  { "id": 1, "task": "需求分析", "start": "2024-01-01", "end": "2024-01-15", "progress": 100 },
  { "id": 2, "task": "UI设计", "start": "2024-01-10", "end": "2024-02-01", "progress": 60 }
]
```
- **设计注意事项**: 
  - 今日线醒目标注
  - 任务条颜色区分状态/负责人
  - 支持拖拽调整时间
  - 里程碑用菱形标记
  - 依赖关系用箭头连接

## 16. 瀑布图（Waterfall Chart）
- **最佳用途**: 展示数值的增减变化过程
- **使用场景**: 财务分析（利润构成）、库存变化、预算差异、人口变动
- **推荐库**: 
  - React: Recharts
  - Vue: Vue-ECharts
  - 原生: ECharts, D3.js
- **数据格式示例**:
```json
[
  { "category": "期初余额", "value": 1000, "type": "total" },
  { "category": "收入", "value": 500, "type": "increase" },
  { "category": "支出", "value": -300, "type": "decrease" },
  { "category": "期末余额", "value": 1200, "type": "total" }
]
```
- **设计注意事项**: 
  - 增加用绿色，减少用红色，合计用蓝色/灰色
  - 连接线显示增减的连续性
  - 数值标签放在柱顶/柱底
  - 合计项使用不同样式区分

## 17. 箱线图（Box Plot）
- **最佳用途**: 展示数据的分布和离群值
- **使用场景**: 成绩分布、薪资分析、实验数据、质量检测
- **推荐库**: 
  - React: Nivo
  - Vue: Vue-ECharts
  - 原生: ECharts, D3.js
- **数据格式示例**:
```json
[
  { "category": "A班", "min": 45, "q1": 60, "median": 75, "q3": 85, "max": 98, "outliers": [30, 100] },
  { "category": "B班", "min": 50, "q1": 65, "median": 78, "q3": 88, "max": 95 }
]
```
- **设计注意事项**: 
  - 标注中位数线
  - 离群值用单独的点标记
  - 箱体宽度一致
  - 提供图例解释各部分含义
  - 悬停显示五数概括

## 18. 仪表盘图（Gauge Chart）
- **最佳用途**: 展示单个指标的当前值和目标范围
- **使用场景**: 速度表、KPI达成率、服务器负载、温度计
- **推荐库**: 
  - React: Recharts
  - Vue: Vue-ECharts
  - 原生: ECharts, D3.js
- **数据格式示例**:
```json
{
  "value": 72,
  "min": 0,
  "max": 100,
  "ranges": [
    { "from": 0, "to": 40, "color": "#22c55e" },
    { "from": 40, "to": 70, "color": "#f59e0b" },
    { "from": 70, "to": 100, "color": "#ef4444" }
  ]
}
```
- **设计注意事项**: 
  - 色彩分区直观（绿→黄→红）
  - 中心显示当前数值
  - 指针样式简洁
  - 刻度标注清晰
  - 适合仪表盘场景

## 19. 地图（Choropleth Map）
- **最佳用途**: 展示地理区域的数据分布
- **使用场景**: 销售区域分布、疫情地图、选举结果、人口密度
- **推荐库**: 
  - React: React-Simple-Maps, Nivo
  - Vue: Vue-ECharts
  - 原生: ECharts, D3.js (TopoJSON), Leaflet
- **数据格式示例**:
```json
[
  { "region": "北京", "value": 2189 },
  { "region": "上海", "value": 2487 },
  { "region": "广东", "value": 12601 }
]
```
- **设计注意事项**: 
  - 使用等值线色阶
  - 提供色阶图例
  - 悬停显示区域名称和数值
  - 注意地图投影方式
  - 小区域可放大显示

## 20. 关系图（Network Graph）
- **最佳用途**: 展示实体之间的关系和连接
- **使用场景**: 社交网络、知识图谱、依赖关系、组织架构
- **推荐库**: 
  - React: React Force Graph, Cytoscape.js
  - Vue: Vue-ECharts
  - 原生: D3.js (force), ECharts, Cytoscape.js
- **数据格式示例**:
```json
{
  "nodes": [
    { "id": "1", "name": "用户A", "group": 1 },
    { "id": "2", "name": "用户B", "group": 2 }
  ],
  "links": [
    { "source": "1", "target": "2", "value": 5 }
  ]
}
```
- **设计注意事项**: 
  - 节点大小映射重要性
  - 连线粗细映射关系强度
  - 颜色区分类别
  - 支持拖拽和缩放
  - 大量节点时使用力导向布局

## 21. 瀑布流图（Streamgraph）
- **最佳用途**: 展示多类别数据随时间的变化和流动
- **使用场景**: 音乐流派流行度、话题热度变化、主题分布演变
- **推荐库**: 
  - React: Nivo
  - Vue: Vue-ECharts
  - 原生: D3.js
- **数据格式示例**:
```json
[
  { "date": "2024-01", "摇滚": 30, "流行": 45, "电子": 25 },
  { "date": "2024-02", "摇滚": 28, "流行": 50, "电子": 30 }
]
```
- **设计注意事项**: 
  - 使用对称布局居中
  - 颜色区分各流
  - 悬停高亮当前流
  - 流动动画增强感知
  - 适合展示有机变化

## 22. 子弹图（Bullet Chart）
- **最佳用途**: 展示指标相对于目标的达成情况
- **使用场景**: 销售目标达成、KPI监控、预算执行、绩效评估
- **推荐库**: 
  - React: Nivo
  - Vue: Vue-ECharts
  - 原生: D3.js, ECharts
- **数据格式示例**:
```json
{
  "title": "收入",
  "measures": [ { "value": 275 } ],
  "ranges": [ { "min": 0, "max": 200 }, { "min": 200, "max": 300 }, { "min": 300, "max": 400 } ],
  "markers": [ { "value": 300 } ]
}
```
- **设计注意事项**: 
  - 灰色背景条表示范围区间
  - 深色条表示实际值
  - 竖线标记目标值
  - 水平方向更常见
  - 适合仪表盘紧凑布局

## 23. 烛台图（Candlestick Chart）
- **最佳用途**: 展示金融数据的开盘/收盘/最高/最低
- **使用场景**: 股票行情、加密货币、期货交易、外汇
- **推荐库**: 
  - React: Recharts, lightweight-charts
  - Vue: Vue-ECharts
  - 原生: ECharts, TradingView Lightweight Charts
- **数据格式示例**:
```json
[
  { "date": "2024-01-01", "open": 100, "close": 105, "high": 110, "low": 95 },
  { "date": "2024-01-02", "open": 105, "close": 98, "high": 108, "low": 96 }
]
```
- **设计注意事项**: 
  - 涨（收盘>开盘）用绿色/空心，跌用红色/实心（中国市场相反）
  - 配合成交量柱状图
  - 支持缩放和拖拽
  - 添加均线等技术指标
  - 十字光标显示精确数值

## 24. 极坐标图（Polar Chart）
- **最佳用途**: 在极坐标系中展示周期性或方向性数据
- **使用场景**: 风向分布、24小时活跃度、月度周期、方向数据
- **推荐库**: 
  - React: Recharts
  - Vue: Vue-ECharts
  - 原生: Chart.js, ECharts
- **数据格式示例**:
```json
[
  { "direction": "北", "value": 15 },
  { "direction": "东北", "value": 25 },
  { "direction": "东", "value": 35 }
]
```
- **设计注意事项**: 
  - 适合展示方向/周期性数据
  - 角度均匀分布
  - 径向距离映射数值
  - 标签放在外侧
  - 与雷达图区分：极坐标图不强调维度对比

## 25. 旭日图（Sunburst Chart）
- **最佳用途**: 展示多层级数据的占比和构成
- **使用场景**: 文件系统结构、组织架构、产品分类、预算层级
- **推荐库**: 
  - React: Nivo
  - Vue: Vue-ECharts
  - 原生: ECharts, D3.js
- **数据格式示例**:
```json
{
  "name": "公司",
  "children": [
    { "name": "技术部", "children": [
      { "name": "前端组", "value": 15 },
      { "name": "后端组", "value": 20 },
      { "name": "运维组", "value": 8 }
    ]},
    { "name": "市场部", "children": [
      { "name": "品牌组", "value": 10 },
      { "name": "渠道组", "value": 12 }
    ]}
  ]
}
```
- **设计注意事项**: 
  - 内圈为父级，外圈为子级
  - 角度大小映射数值占比
  - 使用同色系不同明度区分层级
  - 支持点击下钻
  - 悬停高亮当前路径
  - 中心区域可显示当前层级信息

### 图表设计通用原则

1. **数据墨水比最大化**: 每一抹墨水都应传达数据信息，减少装饰性元素
2. **6秒法则**: 用户应在6秒内理解图表的核心信息
3. **标注优先**: 直接标注 > tooltip > 图例
4. **色彩一致**: 同一数据在不同图表中使用相同颜色
5. **响应式适配**: 图表在移动端应可读，考虑简化或切换图表类型
6. **无障碍**: 图表提供文字替代描述（aria-label），不依赖颜色传达信息
