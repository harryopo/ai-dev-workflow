# 生成艺术与视觉设计子技能

## 0. 执行前置条件（调研守卫）

> ⚠️ **完整工作流模式下**：必须接收 research 阶段的 Design Brief（至少包含品牌人格和情绪板），产出视觉论文时必须引用 Design Brief。

### 完整工作流检查

| 条件 | 检查方式 |
|------|---------|
| Design Brief 存在 | 检查 `pass-data.yaml` 或其他传递机制，确认包含 `brand-personality` 和 `mood-board` 字段 |
| 不存在 Design Brief | 仍可执行创作，但视觉论文产出时标注「无调研数据，基于用户原始描述推导」，并向主入口报告应补充调研 |

### 独立调用检查

若独立调用（非完整工作流串联），根据输出模式判断：

| 输出模式 | 场景 | 是否需要最小化询问 |
|----------|------|:---:|
| 生成艺术（p5.js） | 纯艺术创作 | 不需要（艺术创作自由度高） |
| 视觉设计（海报） | 品牌相关物料 | **需要询问**：用途/受众/风格偏好（但不可从全局画像提取） |

### 全局画像禁令

- ❌ 不从用户全局画像提取艺术风格偏好
- ❌ 不从历史记忆提取配色方案
- ❌ 不从 ontology 提取品牌人格
- 每次创作基于本次请求的上下文，而非跨会话持久化数据

---

本技能合并了 creative-art、canvas-design、algorithmic-art 三个技能的完整功能，支持两种输出模式：

- **生成艺术模式**：交互式 p5.js 生成艺术（HTML），适用于算法艺术、粒子系统、flow field 等
- **视觉设计模式**：静态博物馆/杂志级海报（PDF/PNG），适用于海报设计、视觉设计、品牌物料等

创作流程始终遵循：**设计灵魂继承 → 哲学宣言 → 隐含概念提炼 → 代码/画布表达**。

**关键要求：哲学宣言必须产出「视觉论文」，包含具体的视觉决策方向（配色、排版、布局），该论文将作为 theme 和 design 子技能的输入。**

## 工作流程

### Step 1: 创作哲学宣言 (.md)

无论哪种模式，都从创建一个哲学宣言开始。这是整个创作过程的灵魂。

#### 命名运动（1-2词）

为你的创作哲学命名一个运动，例如：
- "有机湍流" / "量子谐波" / "极简冥想" / "几何沉默"
- "递归低语" / "随机结晶" / "场动力学" / "涌现静止"
- "混凝土诗歌" / "色彩语言" / "模拟冥想" / "有机系统"

#### 阐述哲学（4-6段）

哲学宣言的侧重点因模式不同而异：

**关键要求：哲学宣言必须包含「视觉论文」部分，明确回答以下 5 个问题：**
1. **配色方向**：主色是什么情绪？（冷峻/温暖/高对比/单色/渐变或纯色）
2. **排版方向**：标题用什么性格？（几何/人文/机械/手写/古典）正文用什么性格？
3. **布局方向**：对称还是不对称？网格还是自由？密集还是留白？
4. **材质方向**：扁平还是有质感？光滑还是粗糙？透明还是实心？
5. **动效方向**：静止还是流动？机械还是有机？快速还是缓慢？

#### 视觉论文·动效方向扩展

在 creative 阶段输出视觉论文时，动效方向新增以下选项：

| 动效方向 | 关键词 | 对应组件 |
|---------|--------|---------|
| Shader Effects | "着色器"/"噪点"/"光束"/"像素" | Dither + Noise + Beams |
| Text Effects | "文字动效"/"翻转"/"加密" | Squiggly + Encrypted + Flipping |
| 3D Scene | "3D"/"三维"/"Three.js" | 3D Globe + 3D Scene |
| Micro-interaction | "微交互"/"磁吸"/"弹性" | Magnetic + Spotlight + Gooey |

> **约束**：动效选择必须与品牌人格匹配。极客工程师 → Text Effects + Shader；优雅艺术家 → 3D + 微交互；极简主义者 → 仅 hover 过渡；温暖朋友 → 弹性动效。

**视觉论文必须引用 Design Brief 中的品牌人格和情绪板，确保设计灵魂的一致性。**

**生成艺术模式**强调：
- **计算过程与数学关系**：算法如何通过数学运算创造美感？计算过程的哪些特性使结果令人惊叹？
- **噪声函数与随机模式**：Perlin噪声、Simplex噪声如何驱动有机涌现？随机性如何被约束为受控混沌？
- **粒子行为与场动力学**：粒子如何响应力场？群体行为如何产生涌现复杂性？
- **时间演化与系统状态**：系统如何随时间演化？平衡态与动态平衡如何达成？
- **参数化变异与涌现复杂性**：参数微调如何产生质的飞跃？简单规则如何涌现复杂行为？

**视觉设计模式**强调：
- **空间与形式**：空间如何塑造感知？形式如何传达意义？正负空间的张力如何构建视觉叙事？
- **色彩与材质**：色彩如何作为信息系统？材质如何传达触感与温度？色彩交互如何创造深度？
- **尺度与节奏**：尺度对比如何创造戏剧性？视觉节奏如何引导目光？重复与变异如何建立韵律？
- **构图与平衡**：不对称平衡如何比对称更有力？视觉重力如何分布？构图如何创造动态张力？
- **视觉层次**：如何通过层次引导阅读顺序？信息密度如何控制？留白如何成为最强大的设计元素？

#### 通用关键准则

- **避免冗余**：每个方面只提及一次，除非增加新深度。避免重复关于噪声理论、粒子动力学、色彩原理或排版原则的概念。
- **反复强调工艺**：哲学必须多次强调最终作品应该看起来像是花了无数小时精心打造的，是经过精心打磨的，来自该领域绝对顶尖的人之手。反复使用诸如"精心打磨的算法"、"深厚专业知识的产物"、"煞费苦心的优化"、"大师级实现"等表述。
- **留白创意空间**：对方向要具体，但要足够简洁，让下一个 Claude 有空间在极高的工艺水平上做出诠释性的实现选择。

#### 哲学示例

**"有机湍流"**（生成艺术模式）
哲学：受自然法则约束的混沌，从无序中涌现的秩序。
算法表达：由分层 Perlin 噪声驱动的流场。数千粒子沿向量力流动，轨迹累积形成有机密度图。多重噪声八度创造湍流区域与平静地带。色彩从速度与密度中涌现——快速粒子燃烧明亮，慢速粒子褪入阴影。算法运行至平衡——一个精心调校的平衡态，每个参数都经过大师级计算美学的无数次迭代精炼。

**"量子谐波"**（生成艺术模式）
哲学：离散实体展现类波干涉图样。
算法表达：粒子在网格上初始化，每个携带通过正弦波演化的相位值。当粒子靠近时，它们的相位干涉——相长干涉创造明亮节点，相消干涉创造虚空。简谐运动生成复杂的涌现曼陀罗。这是煞费苦心的频率校准结果，每个比率都经过精心选择以产生共振之美。

**"极简冥想"**（视觉设计模式）
哲学：通过纹理与呼吸空间实现安静的视觉冥想。
视觉表达：纸张纹理、墨水晕染、广阔负空间。摄影与插画主导。排版低语（小型、克制、服务于视觉）。日式写真书美学。图像在页面间呼吸。文字稀疏出现——短句，从不是解释性段落。每幅构图都如同冥想练习般精心平衡。

**"递归低语"**（生成艺术模式）
哲学：跨尺度的自相似性，有限空间中的无限深度。
算法表达：递归细分的分支结构。每个分支略微随机化但受黄金比例约束。L-system 或递归细分生成既数学又有机的树状形态。微妙的噪声扰动打破完美对称。线宽随递归层级递减。每个分支角度都是深度数学探索的产物。

**"随机结晶"**（生成艺术模式/视觉设计模式通用）
哲学：随机过程结晶为有序结构。
算法表达/视觉表达：随机化圆形填充或 Voronoi 镶嵌。从随机点开始，让它们通过松弛算法演化。单元推开直到平衡。颜色基于单元大小、邻居数量或距中心距离。涌现的有机铺贴既随机又不可避免。每个种子产生独特的结晶之美——大师级生成算法的标志。

**"几何沉默"**（视觉设计模式）
哲学：纯粹的秩序与克制。
视觉表达：基于网格的精确性，大胆的摄影或鲜明图形，戏剧性的负空间。排版精确但极简——小型必要文本，大片安静区域。瑞士形式主义遇上粗野主义的材料诚实。结构传达信息，而非文字。每个对齐都是无数次精炼的成果。

**"混凝土诗歌"**（视觉设计模式）
哲学：通过纪念性形式与大胆几何进行交流。
视觉表达：巨大的色块、雕塑式排版（巨大的单个词汇、微小的标签）、粗野主义空间分割、波兰海报能量遇上 Le Corbusier。通过视觉重量与空间张力表达思想，而非解释。文字作为罕见的、有力的姿态——从不是段落，只有融入视觉建筑的必要词汇。每个元素都以大师工匠的精确度放置。

*以上为精简示例。实际的创作哲学应为4-6个充实段落。*

#### 基本原则

- **哲学先行**：创建一个计算/视觉世界观，通过代码/设计表达
- **过程优于产品**（生成艺术模式）：始终强调美从算法执行中涌现——每次运行都是唯一的
- **参数化表达**（生成艺术模式）：思想通过数学关系、力、行为传达——而非静态构图
- **极简文字**（视觉设计模式）：文字始终稀疏、仅限必要、作为视觉元素整合——从不是冗长的
- **空间表达**（视觉设计模式）：思想通过空间、形式、色彩、构图传达——而非段落
- **艺术自由**：下一个 Claude 诠释哲学——提供创意空间
- **纯粹创作**：这是关于制作活算法（生成艺术）或艺术物件（视觉设计），而非带装饰的文档
- **专家工艺**：反复强调最终作品必须看起来像是精心打造的、经过无数小时打磨的、来自该领域顶尖专家的产物

**创作哲学应为4-6段长。** 用诗意的计算/设计哲学填充，将核心愿景凝聚在一起。避免重复相同观点。输出创作哲学为 .md 文件。

### Step 1.5: 提炼隐含概念

**关键步骤**：在实现算法/画布之前，识别原始请求中的微妙概念线索。

**核心原则**：概念是嵌入作品中的微妙、小众引用——不总是字面的，总是精致的。熟悉主题的人应该直觉地感受到它，而其他人只是体验一件大师级的生成构图/抽象构图。哲学提供了计算/视觉语言。提炼的概念提供了灵魂——安静的概念DNA无形地编织进参数、行为和涌现模式（生成艺术）或形式、色彩和构图（视觉设计）中。

**这非常重要**：引用必须如此精致，以至于在不宣告自身的情况下增强作品的深度。像爵士音乐家通过和声引用另一首歌——只有知道的人才会捕捉到，但每个人都欣赏生成之美/音乐之美。

### Step 2A: 生成艺术模式（p5.js 交互式 HTML）

在哲学和概念框架建立后，通过代码表达。在继续之前暂停整理思路。仅使用创建的算法哲学和以下指令。

#### 前置：读取模板

**关键：在编写任何 HTML 之前：**

1. **读取** `templates/viewer.html` 使用 Read 工具
2. **研究** 其精确结构、样式和 Anthropic 品牌
3. **以该文件为字面起点**——不仅是灵感
4. **保留所有固定部分**（头部、侧边栏结构、Anthropic 颜色/字体、种子控件、操作按钮）
5. **仅替换变量部分**，在文件注释中标记（算法、参数、参数的 UI 控件）

**避免：**
- 从头创建 HTML
- 发明自定义样式或配色方案
- 使用系统字体或深色主题
- 更改侧边栏结构

**遵循：**
- 复制模板的精确 HTML 结构
- 保持 Anthropic 品牌（Poppins/Lora 字体、浅色、渐变背景）
- 维护侧边栏布局（Seed → Parameters → Colors? → Actions）
- 仅替换 p5.js 算法和参数控件

模板是基础。在其上构建，不要重建它。

#### 技术要求

**种子随机（Art Blocks 模式）**：

```javascript
// 始终使用种子以确保可重现性
let seed = 12345; // 或用户输入的哈希
randomSeed(seed);
noiseSeed(seed);
```

**参数结构——遵循哲学**：

要建立从算法哲学自然推导的参数，考虑："这个系统的哪些品质可以调整？"

```javascript
let params = {
  seed: 12345,  // 始终包含种子以确保可重现性
  colorPalette: ['#d97757', '#6a9bcc', '#788c5d', '#b0aea5'],
  // 添加控制你算法的参数：
  // - 数量（多少？）
  // - 尺度（多大？多快？）
  // - 概率（多可能？）
  // - 比率（什么比例？）
  // - 角度（什么方向？）
  // - 阈值（行为何时改变？）
};
```

**要设计有效的参数，专注于系统需要可调的属性，而不是以"模式类型"来思考。**

**核心算法——表达哲学**：

**关键**：算法哲学应该决定构建什么。

要通过代码表达哲学，避免思考"我应该使用哪种模式？"，而是思考"如何通过代码表达这个哲学？"

如果哲学关于**有机涌现**，考虑使用：
- 随时间累积或生长的元素
- 受自然规则约束的随机过程
- 反馈循环和交互

如果哲学关于**数学之美**，考虑使用：
- 几何关系和比率
- 三角函数和谐波
- 精确计算创造意外图案

如果哲学关于**受控混沌**，考虑使用：
- 严格边界内的随机变异
- 分岔和相变
- 从无序中涌现的秩序

**算法从哲学中流出，而非从选项菜单中选择。**

让概念本质指导创意和原创选择。构建表达这个特定请求愿景的东西。

**画布标准结构**：

```javascript
function setup() {
  createCanvas(1200, 1200);
  // 初始化你的系统
}

function draw() {
  // 你的生成算法
```

#### 工艺要求

**关键**：要达到大师级水平，创建看起来像是大师级生成艺术家通过无数次迭代涌现的算法。仔细调校每个参数。确保每个模式都有目的地涌现。这不是随机噪声——这是通过深厚专业知识精炼的受控混沌。

- **平衡**：复杂而不视觉噪声，有序而不僵化
- **色彩和谐**：深思熟虑的调色板，而非随机 RGB 值
- **构图**：即使在随机性中，也保持视觉层次和流动
- **性能**：流畅执行，如动画则优化为实时
- **可重现性**：相同种子始终产生相同输出

#### 交互功能要求

**1. 参数控件**
- 数值参数的滑块（粒子数量、噪声尺度、速度等）
- 调色板的颜色选择器
- 参数变更时实时更新
- 重置按钮恢复默认值

**2. 种子导航**
- 显示当前种子编号
- "Previous"和"Next"按钮循环种子
- "Random"按钮随机种子
- 输入框跳转到特定种子
- 请求时生成100个变体（种子1-100）

**3. 单文件结构**


**关键**：这是单个工件。没有外部文件，没有导入（p5.js CDN 除外）。一切内联。

**4. 侧边栏结构**

侧边栏布局必须遵循以下顺序：
- **Seed** 部分：种子显示、Previous/Next 按钮、Random 按钮、Jump 输入 + Go 按钮
- **Parameters** 部分：自定义滑块和控件
- **Colors** 部分（可选）：颜色选择器（某些艺术需要，某些使用固定颜色，某些单色）
- **Actions** 部分：Regenerate 按钮、Reset 按钮

**5. 固定 vs 变量**

**固定（始终按原样包含）：**
- 布局结构（头部、侧边栏、主画布区域）
- Anthropic 品牌（UI 颜色、字体、渐变）
- 侧边栏中的 Seed 部分
- 侧边栏中的 Actions 部分

**变量（为每件作品自定义）：**
- 整个 p5.js 算法（setup/draw/classes）
- 参数对象
- 侧边栏中的 Parameters 部分
- Colors 部分（可选，取决于艺术需求）

每件作品应有独特的参数和算法！固定部分提供一致的 UX——其他一切表达独特的愿景。

### Step 2B: 视觉设计模式（PDF/PNG 静态海报）

在哲学和概念框架建立后，在画布上表达。花点时间整理思路和清空头脑。使用创建的设计哲学和以下指令打造杰作，以专家工艺体现哲学的所有方面。

**重要**：对于任何类型的内容，即使用户请求电影/游戏/书籍相关的内容，方法仍应精致。永远不要忘记这应该是艺术，而非卡通化或业余的东西。

#### 画布创作

要创建博物馆或杂志品质的作品，使用设计哲学作为基础。创建一个单页、高度视觉化、设计驱动的 PDF 或 PNG 输出（除非要求更多页面）。通常使用重复图案和完美形状。将抽象哲学设计视为科学圣经，借用系统观察的视觉语言——密集的标记积累、重复元素或分层图案通过耐心的重复建立意义并回报持续观看。添加稀疏、临床排版和系统参考标记，暗示这可能是来自想象学科的图表，以通常保留给记录可观察现象的崇敬对待隐形主题。用简单短语或细节微妙定位来锚定作品，使用感觉有意且凝聚的有限调色板。拥抱使用分析视觉语言表达人类体验思想的悖论：结果应该感觉像是一件证明某些短暂之物可以通过仔细关注被研究、映射和理解的文物。这是真正的艺术。

**文字作为语境元素**：文字始终是最小化和视觉优先的，但让上下文指导这意味着低语般的标签还是大胆的排版姿态。朋克场地海报可能有比极简主义陶瓷工作室标识更大、更具攻击性的字体。大多数时候，字体应该细。所有字体的使用必须以设计为导向，优先考虑视觉传达。无论文字尺度如何，没有任何东西超出页面，没有任何东西重叠。每个元素必须包含在画布边界内，具有适当的边距。仔细检查所有文本、图形和视觉元素有呼吸空间和清晰分离。这对专业执行是不可协商的。

**重要：书写文字时使用不同字体。搜索 `canvas-fonts` 目录。无论采用何种方法，精致是不可协商的。**

下载并使用所需的任何字体使其成为现实。通过使排版实际成为艺术本身的一部分来发挥创意——如果艺术是抽象的，将字体带到画布上，而非数字化排版。

要推动边界，遵循设计直觉/直觉，同时使用哲学作为指导原则。拥抱终极设计自由和选择。将美学和设计推向前沿。

**关键**：要达到人类工艺品质（非 AI 生成），创建看起来像是花了无数小时的作品。使其看起来像是该领域绝对顶尖的人煞费苦心地打磨每个细节。确保构图、间距、色彩选择、排版——一切都尖叫专家级工艺。反复检查没有重叠，格式完美无瑕，每个细节完美。创建可以向人们展示以证明专业知识的作品，排名为无可否认的令人印象深刻。

输出最终结果为单个可下载的 .pdf 或 .png 文件，以及设计哲学 .md 文件。

#### 最终步骤

**重要**：用户已经说过"它还不够完美。它必须是原始的，工艺的杰作，仿佛即将在博物馆展出。"

**关键**：要精炼作品，避免添加更多图形；而是精炼已创建的内容并使其极其清晰，完全尊重设计哲学和极简主义原则。与其添加有趣的滤镜或重构字体，不如考虑如何使现有构图更具有艺术性。如果本能是调用新函数或绘制新形状，停下来，改为问："如何让已有的东西更像一件艺术品？"

进行第二遍打磨。回到代码，进一步精炼/打磨，使其成为哲学设计的杰作。

## 注意事项

1. **模板是起点，不是灵感**——必须从模板文件字面开始，保留所有固定部分
2. **算法是创造独特作品的地方**——不要复制 flow field 示例，构建哲学要求的东西
3. **保持模板的精确 UI 结构和品牌设计**——Anthropic 品牌、Poppins/Lora 字体、浅色主题
4. **不要从零创建 HTML**——始终从 templates/viewer.html 开始
5. **原创性**：创建原创算法艺术/视觉设计，而非复制现有艺术家的作品以避免版权问题
6. **工艺至上**：最终作品必须看起来像是该领域顶尖专家花费无数小时精心打造的
7. **单文件原则**（生成艺术模式）：所有代码内联在一个 HTML 文件中，仅 p5.js 从 CDN 加载
8. **文字克制**（视觉设计模式）：文字始终稀疏、仅限必要、作为视觉元素整合
9. **可重现性**（生成艺术模式）：相同种子始终产生相同输出
10. **精致不可协商**：无论哪种模式，输出品质必须达到博物馆/杂志级别
