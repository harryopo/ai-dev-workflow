# 场景示例：复杂任务（占比 15%）

## 场景描述
用户需要大规模重构或架构设计，涉及多个模块。

## 优化前
- 加载完整 CLAUDE.md：~16,000 tokens
- 所有模板和流程：~3,000 tokens
- 总计：~19,000 tokens

## 优化后
- 加载精简 CLAUDE.md：~9,200 tokens
- 加载多个 Skills：~9,700 tokens
- 总计：~18,900 tokens

## 节省效果
- Token 节省：0.5%（复杂任务需要加载大部分 Skills）
- 信息保留率：100%
- 说明：复杂任务的优化空间有限，但简单和中等任务的节省弥补了这一点
