**优化时间：** 2026-06-18

## 一、问题分析

| 主 SKILL.md | 版本历史表 | ~10 行 |

| dev/SKILL.md | 合并流程标题中的版本说明 | ~1 行 |

| review/SKILL.md | 更新日志表 | ~8 行 |

**总计：约 70+ 行"消耗 token 但调取时没用"的内容**

---

## 二、优化方案

### 2.1 优化原则

1. **SKILL.md 只保留执行指令** — 版本信息、更新历史、优势介绍等移到 README.md
2. **版本号只在 frontmatter 中保留** — 标题中不重复版本号
3. **移除"v5.x 新增"标签** — 这些标签对执行没有帮助
4. **移除版本历史表** — 应该放在 README.md

### 2.2 移除内容清单

| 内容类型 | 移除位置 | 移至 |
|----------|----------|------|
| 版本更新概述 | description | README.md |
| 版本号 | 标题 | frontmatter |
| 版本标签 | 核心原则 | 移除 |
| 版本说明 | 流程标题 | 移除 |
| 版本标签 | 参考资料 | 移除 |
| 版本历史表 | SKILL.md | README.md |
| 更新日志 | review/SKILL.md | README.md |

## 六、总结

### 6.1 优化效果

- **Token 节省：** 每次调用节省约 350-400 token
- **信息保留：** 所有执行指令和问话清单完整保留
- **可追溯性：** 版本历史和更新日志统一在 README.md 中

### 6.2 设计原则

1. **SKILL.md = 执行指令** — 只包含 LLM 执行时需要的内容
2. **README.md = 项目说明** — 包含版本历史、更新日志、核心特性等介绍性内容
3. **references/ = 参考资料** — 包含详细的方法论、模板、规范等
