# Desktop Application Patterns — 桌面应用设计模式库

> 适用于 Electron、Tauri、PySide6、Qt 等桌面应用框架。
> 本文件定义了桌面应用的核心 UI 模式和交互惯例。

---

## 1. 桌面应用设计原则

### 核心特征

桌面应用与网页应用的核心差异：

| 维度 | 桌面应用 | 网页应用 |
|------|---------|---------|
| 窗口管理 | 多窗口、浮动面板、分屏 | 单页应用 |
| 输入方式 | 鼠标+键盘为主，触摸为辅 | 触摸+鼠标 |
| 屏幕空间 | 充分利用大屏，密度可高 | 响应式适配 |
| 持久状态 | 文件系统访问、系统托盘 | 无 |
| 系统集成的 | 原生对话框、拖放、剪贴板 | 受限 |

### 设计优先级

1. **效率优先**：键盘快捷键、Command Palette、快速操作
2. **信息密度**：充分利用桌面屏幕空间，数据密度可高于网页
3. **系统一致性**：遵循操作系统设计规范（macOS HIG / Windows Fluent / Linux HIG）
4. **离线可用**：支持离线状态提示和恢复
5. **窗口管理**：合理处理多窗口、浮动面板和分屏布局

## 2. 核心 UI 模式

### 2.1 Command Palette（命令面板）

桌面应用最核心的交互模式之一。

```
布局结构：
┌────────────────────────────────────────┐
│ 🔍 搜索命令...              ⌘K        │
├────────────────────────────────────────┤
│ → 新建项目                            │
│   打开文件...                           │
│   切换主题                            │
│   运行任务...                           │
└────────────────────────────────────────┘
```

**设计规则：**
- 快捷键固定：`Cmd+K`（macOS）/ `Ctrl+K`（Windows/Linux）
- 输入时实时过滤，不区分大小写
- 支持模糊匹配和关键词排序
- 最多显示 8-12 条结果
- 支持分组显示（命令 / 文件 / 历史）
- ESC 关闭，Enter 执行选中项
- 首次打开时聚焦输入框

**实现模式：**
- 浮层覆盖，不改变底层布局
- 背景半透明模糊（backdrop-blur）
- 居中或偏上定位

---

### 2.2 三栏布局（经典桌面）

最经典的桌面应用布局，适用于 IDE、文档编辑器、设计工具。

```
┌──────────┬────────────────────┬──────────┐
│ 文件树    │                    │ 属性面板  │
│          │                    │          │
│ Folder A │                    │ 属性1    │
│  File 1  │      主工作区        │ 属性2    │
│  File 2  │                    │ 属性3    │
│ Folder B │                    │          │
│  File 3  │                    │ 预览     │
└──────────┴────────────────────┴──────────┘
```

**设计规则：**
- 侧栏宽度固定：文件树 200-250px，属性面板 250-320px
- 主工作区弹性填充剩余空间
- 每栏可拖拽调整宽度
- 最左侧栏可折叠隐藏（汉堡按钮或拖拽）
- 工作区顶部保留工具栏/面包屑
- 底部保留状态栏（可选）

**适用场景：**
- 代码编辑器（VS Code 风格）
- 文件管理器
- 设计工具（Figma 左侧面板）
- 资产管理工具

---

### 2.3 主侧栏布局

适用于内容丰富的桌面应用，侧栏作为主要导航。

```
┌─────────┬──────────────────────────────────┐
│ Logo    │  工具栏 / 面包屑                  │
│         ├──────────────────────────────────┤
│ 🏠 首页  │                                  │
│ 📁 项目  │         主内容区                  │
│ 👤 用户  │                                  │
│ ⚙️ 设置  │                                  │
└─────────┴──────────────────────────────────┘
```

**设计规则：**
- 侧栏宽度 200-240px
- 侧栏可折叠为图标栏（56-64px）
- 当前选中项高亮显示
- 支持分组和折叠菜单
- 底部可放置用户信息/设置入口

---

### 2.4 浮动面板/Inspector

浮动面板覆盖在主内容之上，不改变底层布局。

```
┌────────────────────────────────────────┐
│                                        │
│              主内容区域                  │
│                                        │
├────────────────────────────────────────┤
│  浮动面板                                  │
│  ┌─────────────────────────────────┐  │
│  │ 样式检查器                       │  │
│  │ ─────────────────────────────  │  │
│  │ 填充: [██████] #3b82f6          │  │
│  │ 圆角: 8px                       │  │
│  │ 阴影: md                        │  │
│  │ 边距: [8] [8] [8] [8]          │  │
│  │                                 │  │
│  │ [应用]      [重置]    ✕          │  │
│  └─────────────────────────────────┘  │
└────────────────────────────────────────┘
```

**设计规则：**
- 默认停在右侧或右侧边缘
- 可拖拽移动位置
- 可折叠为侧边栏
- 面板内滚动不带动全局
- 使用卡片式分组
- 每个字段有明确的标签和说明

**适用场景：**
- 设计工具属性检查器
- 组件样式调整面板
- 文件属性查看器

---

### 2.5 系统托盘图标（Tray）

桌面应用特有的常驻后台模式。

```
系统托盘区域：
┌──────────────────────────────────────────────┐
│ ...  🎵 📶 🔋  [托盘图标]                     │
└──────────────────────────────────────────────┘
```

**托盘功能菜单：**
```
右键菜单：
┌──────────────────┐
│  主界面           │
├──────────────────┤
│  设置            │
├──────────────────┤
│  ───────────    │
│  退出            │
└──────────────────┘
```

**设计规则：**
- 图标简洁，最好提供暗色/亮色两套
- 托盘菜单不要超过 6 项
- 关键状态在菜单中可感知（如播放状态、通知数量）
- 避免在托盘执行耗时操作
- 提供"最小化到托盘"而非"关闭窗口"的体验

---

### 2.6 多窗口管理

桌面应用的多窗口协作模式。

```
场景：
┌──────────────┐    ┌──────────────┐
│  主窗口       │    │  工具窗口     │
│  编辑文档     │◄──►│  文件浏览器   │
│              │    │              │
│  [内容区]     │    │  [文件列表]   │
│              │    │              │
└──────────────┘    └──────────────┘
```

**设计规则：**
- 窗口之间支持自由排列（拖拽、并排、叠加）
- 主窗口保持焦点状态，次级窗口淡化
- 提供窗口对齐辅助线
- 支持悬浮窗口（Always on Top）
- 窗口状态持久化（关闭后重新打开恢复位置/大小）

---

### 2.7 分屏布局

```
┌────────────────────────────────────────┐
│  面板A (可拖拽调整)    │   面板B       │
│                        │               │
│  代码编辑器            │   预览窗口    │
│                        │               │
│                        │               │
└────────────────────────────────────────┘
```

**设计规则：**
- 分栏宽度可拖拽调整
- 支持水平/垂直两种分屏
- 分屏位置可记忆
- 最右侧/底部可放置状态栏
- 避免超过 3 个面板（增加复杂度）

## 3. 窗口管理 API 参考

### Electron Window 管理

```javascript
// 创建新窗口
const win = new BrowserWindow({
  width: 1200,
  height: 800,
  minWidth: 800,
  minHeight: 600,
  titleBarStyle: 'hiddenInset', // macOS 隐藏标题栏
  trafficLightPosition: { x: 12, y: 12 },
  frame: false, // 自定义标题栏
  webPreferences: {
    nodeIntegration: false,
    contextIsolation: true,
  }
});

// 设置图标
win.setAppUserModelId('com.example.app');

// 窗口事件
win.on('close', (e) => {
  // 最小化到托盘而非关闭
  if (process.platform !== 'darwin') {
    e.preventDefault();
    win.hide();
  }
});
```

### Tauri Window 管理

```rust
use tauri::Manager;

// 创建新窗口
app.handle().create_window(
  "tool-window".to_string(),
  tauri::WindowBuilder::new(
    &app,
    "tool-window",
    tauri::WindowUrl::App("index.html".into()),
  )
  .title("工具窗口")
  .inner_size(800.0, 600.0)
  .build()
)?;
```

## 4. 键盘快捷键设计

### 标准快捷键映射

| 操作 | macOS | Windows/Linux |
|------|-------|---------------|
| 新建 | `Cmd+N` | `Ctrl+N` |
| 打开 | `Cmd+O` | `Ctrl+O` |
| 保存 | `Cmd+S` | `Ctrl+S` |
| 撤销 | `Cmd+Z` | `Ctrl+Z` |
| 重做 | `Cmd+Shift+Z` | `Ctrl+Y` |
| 查找 | `Cmd+F` | `Ctrl+F` |
| 替换 | `Cmd+Shift+H` | `Ctrl+H` |
| 全选 | `Cmd+A` | `Ctrl+A` |
| 复制 | `Cmd+C` | `Ctrl+C` |
| 粘贴 | `Cmd+V` | `Ctrl+V` |
| 剪切 | `Cmd+X` | `Ctrl+X` |
| 删除 | `Delete` | `Delete` |
| 撤销/重做 | `Cmd+Z` / `Cmd+Shift+Z` | `Ctrl+Z` / `Ctrl+Y` |
| 命令面板 | `Cmd+K` | `Ctrl+K` |
| 设置 | `Cmd+,` | `Ctrl+,` |
| 关闭当前 | `Cmd+W` | `Ctrl+W` |
| 关闭应用 | `Cmd+Q` | — |

### 快捷键设计规则

1. **遵循操作系统惯例**：macOS 用 Cmd，Windows 用 Ctrl
2. **避免冲突**：不与系统级快捷键冲突
3. **提供可视化提示**：UI 中显示快捷键提示（如 "Save (⌘S)"）
4. **支持组合键**：允许复杂操作使用 modifier 组合
5. **可自定义**：允许用户重新映射快捷键
6. **命令面板优先**：复杂命令优先放命令面板，不必全部暴露快捷键

## 5. 拖放交互

### 文件拖入（Drop Zone）

```
┌────────────────────────────────────┐
│                                    │
│                                    │
│           📂 拖放文件到此处         │
│                                    │
│                                    │
└────────────────────────────────────┘
```

**设计规则：**
- 拖入时高亮显示目标区域（border-dashed + 变色）
- 显示支持的文件类型提示
- 拖放完成后显示预览/上传状态
- 支持多文件批量拖放
- 拖放过程中保持应用可交互

### 内拖放（Element Drag）

```
┌─────────────┐     ┌─────────────┐
│  📄 文件A   │────►│  📁 文件夹B  │
│  (可拖拽)   │     │             │
└─────────────┘     └─────────────┘
```

**设计规则：**
- 拖拽时显示半透明预览
- 拖拽目标高亮显示可放置状态
- 放置后显示过渡动画
- 支持撤销最近一次拖放操作
- 长距离拖放需要滚动容器跟随

## 6. 系统对话框集成

### 文件对话框

```javascript
// Electron
const { dialog } = require('electron');

// 打开文件
dialog.showOpenDialog({
  title: '选择文件',
  filters: [{ name: 'Images', extensions: ['jpg', 'png', 'gif'] }],
  properties: ['openFile', 'multiSelections']
});

// 保存文件
dialog.showSaveDialog({
  title: '保存文件',
  defaultPath: 'untitled.png'
});
```

### 消息对话框

```javascript
// 确认对话框
dialog.showMessageBox({
  type: 'question',
  title: '确认保存',
  message: '文件已修改，是否保存？',
  buttons: ['保存', '放弃', '取消'],
  defaultId: 0,
  cancelId: 2
});
```

**设计规则：**
- 使用系统原生对话框（不要自定义模态框替代）
- 对话框标题明确表达意图
- 按钮文案清晰（避免"确定"/"取消"泛化表述）
- 危险操作需要二次确认
- 提供快捷键支持（Enter 确认，Esc 取消）

## 7. 桌面应用常用组件

### 标题栏

```
┌─────────────────────────────────────────────────┐
│ ● ○ ●  [文档名] — App名称                       │  macOS traffic lights
├─────────────────────────────────────────────────┤
│ 文件  编辑  视图  帮助                          │  菜单栏
├─────────────────────────────────────────────────┤
│  面包屑 / 工具栏                                 │
└─────────────────────────────────────────────────┘
```

**设计规则：**
- macOS：优先使用原生 title bar（traffic lights）
- Windows：使用原生标题栏或自定义框架（frame: false）
- 标题栏高度 28-36px
- 自定义标题栏需保留拖拽区域（-webkit-app-region: drag）
- 避免在标题栏放置过多交互元素

### 菜单栏

```
┌──────────────────────────────────────────────────┐
│ 文件  编辑  视图  插入  格式  工具  窗口  帮助   │
└──────────────────────────────────────────────────┘
```

**标准菜单项：**
- **文件**：新建、打开、保存、导出、打印、退出
- **编辑**：撤销、重做、剪切、复制、粘贴、查找
- **视图**：放大、缩小、重置、分屏、全屏
- **帮助**：关于、快捷键、反馈、文档

### 状态栏

```
┌────────────────────────────────────────────────┐
│ ✓ 就绪  |  行 42 列 15  |  UTF-8  |  LF      │
└────────────────────────────────────────────────┘
```

**设计规则：**
- 高度 24-28px
- 左侧：状态信息（就绪/加载中/错误）
- 中间：上下文信息（位置、计数等）
- 右侧：格式/编码/版本信息
- 每个区域可点击展开更多详情
- 使用分割线分隔不同信息组

## 8. 桌面应用布局模板

### 模板 A：IDE 风格（三栏）

```
布局比例：侧栏 20% | 工作区 60% | 面板 20%
侧栏固定：文件树 / 侧边栏
工作区弹性：编辑器 / 画布
面板固定：属性检查器 / 终端
底部可选：状态栏 / 输出面板
```

### 模板 B：阅读器风格（两栏）

```
布局比例：侧栏 25% | 主内容 75%
侧栏：目录 / 书签 / 文件列表
主内容：可滚动，固定宽度居中
顶部：工具栏 / 搜索
底部：分页 / 进度
```

### 模板 C：编辑器风格（单栏+浮动）

```
布局：全屏单栏
浮动面板：属性检查器、图层面板（可拖拽定位）
工具栏：顶部固定
状态栏：底部固定
侧边栏：可折叠
```

### 模板 D：分屏风格

```
布局：水平或垂直分屏
分栏比例：可拖拽调整
每栏可独立滚动
中间分隔条：可隐藏/显示
```

## 9. 桌面 vs 网页设计差异对照

| 设计维度 | 网页应用 | 桌面应用 |
|---------|---------|---------|
| 首屏高度 | 限制在视口内 | 可无限滚动 |
| 导航 | 顶部导航栏 | 侧栏/菜单栏 |
| 弹窗 | Modal（遮罩） | 系统对话框/浮动面板 |
| 输入 | 触摸友好，大目标 | 键盘优先，精确输入 |
| 信息密度 | 中等（阅读舒适） | 高（效率优先） |
| 动效 | 入场/滚动驱动 | 窗口切换/拖拽/快捷键反馈 |
| 字体 | 灵活缩放 | 跟随系统 DPI |
| 图标 | 小图标即可 | 需要更精细（高 DPI） |
| 主题 | 网页主题 | 跟随系统/原生主题 |
| 快捷键 | 有限 | 核心交互方式 |

## 10. 设计检查清单

桌面应用设计时必须检查：

- [ ] 窗口可缩放（有最小/最大尺寸）
- [ ] 支持自定义标题栏或原生标题栏
- [ ] 键盘快捷键完整且符合平台惯例
- [ ] Command Palette 或等效快速操作
- [ ] 拖放交互体验流畅
- [ ] 系统对话框使用原生（非自定义）
- [ ] 多窗口协作合理
- [ ] 状态栏显示必要信息
- [ ] 侧栏可折叠/展开
- [ ] 分栏宽度可调整
- [ ] 窗口状态持久化（大小/位置）
- [ ] 高 DPI 适配（图标 2x/3x）
- [ ] 菜单栏符合平台规范
- [ ] 系统托盘功能合理
- [ ] 离线状态有提示
- [ ] 窗口阴影/圆角符合平台规范
- [ ] 快捷键提示在 UI 中可见
