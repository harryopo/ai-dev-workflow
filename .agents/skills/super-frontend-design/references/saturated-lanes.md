# 饱和风格赛道清单（Saturated Aesthetic Lanes）

> **为什么存在**：反 AI 味规则（references/anti-ai-slop.md）防的是"AI 默认丑"；本清单防的是另一种同质化——**"参考驱动像"**：整个行业涌向同一种"好看"，识别度归零（"换掉 logo 认不出谁是谁"）。
> 机制借鉴自 impeccable skill 的 reflex-reject aesthetic lanes（过饱和美学赛道 = 二阶训练反射）。
> **用法**：review / critique 阶段对照本清单检查产出；落进赛道且无 register 理由时，标注并建议换方向。

---

## 当前饱和赛道（2026-10 首发）

### 1. Stripe 邻近编辑排版风（Editorial-typographic）
- **指纹**：衬线（常斜体）大标题 + 小号等宽标签 + 分隔线分栏 + 单色克制 + 零图像
- **状态**：2026 年科技品牌大面积落此赛道，成为"高级感"的默认解——已过饱和
- **豁免示例**：字面意义的杂志/出版站（register 理由成立）

### 2. 紫蓝渐变 SaaS 风
- **指纹**：紫→蓝（或青）渐变 + 白底 + 圆角卡片网格 + 浮动玻璃导航 + 三列功能区
- **状态**：AI 生成与模板市场的高频均色；与反 AI 味七宗罪 #1/#2（AI 默认色、两色渐变 Hero）部分重叠，本清单从"整页赛道"层面补充
- **豁免示例**：用户明确要求且产品本身即渐变品牌资产

### 3. Notion 邻近米色风
- **指纹**：米白/暖灰底 + 巨大字号衬线标题 + 大量 emoji 装饰 + 轻边框卡片 + 长文档模板感
- **状态**：识别度已被稀释为"通用生产力工具默认相"
- **豁免示例**：产品核心场景就是文档/知识库且用户点名此方向

---

## register 理由（豁免条件）

赛道命中不等于违规——当设计**确实需要**该赛道时（字面意义的杂志站、字面意义的终端工具、字面意义的印刷品复刻），给出 register 理由即可通过。理由必须具体到场景，不能写"看起来高级"或"用户喜欢"。

## 维护规则

- 赛道随行业饱和度增减：新赛道涌入时加入，回落时移除
- 每条赛道写"指纹"（可判定的特征组合），保证 review 时能对照执行
- 与 references/anti-ai-slop.md 分工：那条清单管**具体元素**（颜色值/字体/布局模式）；本清单管**整体美学家族**
- 与「参考距离分级」配合：分级防"单项目复制参考"，本清单防"全行业挤进同一条赛道"
