# Craft & Polish — 精美的最后一公里（工艺手册）

> 定位：骨架之上的**工艺层**。三层契约保证"有意图"，反 AI 味门禁保证"不烂"，
> 本手册管的是"从合格到惊艳"——色彩敢不敢压注、字体有没有性格、节奏敢不敢变化。
> 使用时机：design 的 Step 5 代码生成前过一遍 §1-§4；refine `/polish` 按 §5 清单逐项打磨。
> 借鉴源：impeccable 的色彩策略与排版纪律 + 本 skill 的 typography.md / canvas-fonts 资产。

---

## 1. 色彩压注：三策略选一，禁止安全平均

"米色底 + 灰字 + 一点蓝"是 AI 输出的默认脸——不是错，是**没做决定**。落 DESIGN.md 前必须选一个压注策略：

| 策略 | 做法 | 适合 | 品牌人格示例 |
|------|------|------|-------------|
| **Committed（单色压注）** | 一个饱和色贯穿主按钮/选中态/强调线，中性色只做骨架 | 大多数产品——识别度最高的性价比解 | 极客工程师、权威专家 |
| **Drenched（整页浸润）** | 品牌色大面积铺底（深色底或高饱和底），文字/组件在色里活 | 敢表态的品牌页、活动页；想被记住就选它 | 叛逆先锋、活力创业者 |
| **Restrained（克制留白）** | 近无彩色 + 极多留白 + 一处精准的彩色（或全灰阶零彩） | 内容本身是主角（摄影/作品集/文档） | 极简主义者、优雅艺术家 |

- 选型挂品牌人格；**选完写进 DESIGN.md §2 的决策记录**（"为什么选这个策略"一句话），review 时核对执行是否彻底
- Committed/Drenched 的纪律：**别在边缘对冲**——选了压注又在四周垫灰白，等于没选
- 文化符号色（科技蓝/金融深蓝）是第一反射——压注前先过 saturated-lanes.md

## 2. Display 字体打法（canvas-fonts 实战配对）

字体是性价比最高的差异化——改一个 display 字体，页面的"脸"就换了。**禁止** Inter/Roboto 系当 display（slop 门禁会拦）。本 skill `canvas-fonts/` 自带 OFL 授权字体（可随产物分发）：

| 想要的气质 | Display 选字体（canvas-fonts） | 配正文 | 典型场景 |
|-----------|------------------------------|--------|---------|
| 当代编辑感、有骨有肉 | **Bricolage Grotesque**（Bold） | Instrument Sans / Work Sans | 品牌官网、SaaS 首页 |
| 数据冲击力、窄高冷峻 | **Big Shoulders**（Bold，超大数字/短标题） | Work Sans | 数据页、体育/工业风 |
| 优雅衬线、杂志质感 | **Gloock** 或 **Young Serif**（Regular） | Work Sans / Instrument Sans | 内容品牌、奢华向 |
| 意大利体点缀（只做 accent 词） | **Instrument Serif Italic** / **Crimson Pro Italic** | 同族 Sans | 在无衬线标题里斜体 1-2 个词，编辑感立现 |
| 复古工业/像素信号 | **Tektur** / **Silkscreen**（小面积标签） | Instrument Sans | 极客/游戏向的 accent |
| 几何极细 | **Poiret One** / **Jura Light**（大字号才可读） | Work Sans | 高级冷淡风（慎用，可读性优先） |

打法三则：
- **字重对比要 committed**：display 用唯一重字重（Bold/Black），正文 Regular——300/500 的中间地带是犹豫的味道；一页 ≤3 个字重（typography.md §6）
- **尺寸对比敢拉大**：H1 与正文的字号比 ≥2（render_probe 会量 <1.5 报警——把 1.5 当下限不是目标）
- **display 字体只给 display**：正文/按钮/表格别跟着换——性格字体大面积铺开就从"签名"变"噪音"

## 3. 间距节奏：反均匀

均匀间距是模板脸的核心成因。4px 网格是底盘（slop 门禁管），**节奏**是上层：

- **分组内紧、分组间松**：同组元素间距用小档（8/12），组间跳档（32/48/64）——亲密性一出来层级就出来
- **Section 间距用阶梯**而非恒定：如 64 → 96 → 128，重要分区前后给更大呼吸
- **留白是胆量指标**：C 端首屏至少敢给一屏 25%+ 的纯负空间；挤满的首屏等于没有焦点
- **一处密集对比**：全页疏朗里放一个高密度区（数据条/参数表），密度差本身就是视觉事件

## 4. 动效打磨清单（入场一次到位）

- **缓动**：入场/位移用强 ease-out（`cubic-bezier(0.16,1,0.3,1)` 系）；回弹只给微交互，不给版面
- **Stagger 编排**：列表入场逐项延迟 40-80ms，方向统一（同向上浮或同向淡入），乱方向=乱码感
- **时长档位**：微反馈 100-150ms / 状态过渡 200-300ms / 入场编排 400-700ms；超过 1s 的非滚动叙事动效要自问"用户第二遍还愿意看吗"
- **一次到位**：入场动画播一次，不循环不重复触发；`prefers-reduced-motion` 降级是门禁（reduced-motion-missing）
- **动效签名**：把品牌"签名识别符"与一种动效绑定（如术语单元永远用打字机揭示）——重复出现才是记忆点

## 5. 「一眼惊艳」终检（refine /polish 逐项过）

- [ ] 打开页面 3 秒内，说得出视觉锚点是什么？锚点全页 ≤2 个
- [ ] 色彩压注策略能说出来吗？说不出 = 没压注（回 §1 重选）
- [ ] display 字体换掉 Inter 系了吗？字重对比 committed 吗？
- [ ] 间距是非均匀节奏吗？随便截两段 section 间距相同 = 回 §3
- [ ] 大小对比够狠吗？（最大字号 / 正文字号 ≥2）
- [ ] 有没有一处"别人没有"的细节（材质/动效/排版处理）——对应签名契约的可见性
- [ ] 移除所有阴影后层次仍成立吗？（边线与底色分层是底气，阴影只是糖）
- [ ] 暗色模式不是反色——两套色各自压注过对比度门禁吗？

## 6. 与既有机制的关系

- 本手册不新增机检——静态可判定的部分已在门禁里（字号比/字重数/间距 4px/reduced-motion）；手册管**门禁量不到的胆量与品味**
- §1 的策略选择与 §2 的字体选型**写进 DESIGN.md 对应 section**，供 review 人工核对"执行是否彻底"
- C 端场景与 creative 的视觉论文联动：压注策略 = color-direction 的具体化；display 字体 = typography-direction 的具体化
