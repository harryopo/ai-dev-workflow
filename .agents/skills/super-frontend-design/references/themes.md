# Themes — 20种命名设计主题

> 本文件定义hallmark的20个命名主题（themes）。
> 每个主题有独特的视觉DNA：配色方向 + 字体组合 + 结构指纹 + 适用场景。
>
> 使用方式：在确定macrostructure后选择theme。theme描述视觉表面，macrostructure描述页面形状。
> 同一项目内连续输出应使用不同theme。
>
> 参考：hallmark (Nutlope/hallmark, MIT)

## 主题详解

### 1. Almanac
- **风格**：数据密集、参考工具风格。粘性标题+三栏等宽+数字滚轮入场。
- **配色**：高对比中性色 + 单一accent用于数据高亮
- **字体**：Sans-serif display + clean body + mono for data
- **适用**：数据工具、参考文档、统计仪表板、年刊
- **推荐macrostructure**：01·Bento Grid、04·Stat-Led
- **品牌人格映射**：数据驱动、权威专家

### 2. Atelier
- **风格**：高端工作室。居中显示+单栏+负间距+打字机入场。
- **配色**：暖中性+单一accent（低饱和）
- **字体**：Refined serif display + fine body
- **适用**：设计工作室、高端品牌、作品集
- **推荐macrostructure**：12·Letter、09·Quote-Led
- **品牌人格映射**：优雅艺术家、奢华高端

### 3. Aurora
- **风格**：抽象概念展示。悬停标题+单栏+无装饰+fade-up入场。
- **配色**：深色背景+单色warm accent + tinted neutrals
- **字体**：Geometric sans display + neutral body
- **适用**：AI/科技概念产品、抽象服务
- **推荐macrostructure**：03·Marquee Hero、07·Manifesto
- **品牌人格映射**：极客工程师、创新先锋

### 4. Bloom
- **风格**：自然/花艺/植物。居中+单栏+无图+fade-up。
- **配色**：绿色系+暖earth tone + soft accent
- **字体**：Organic serif display + warm body
- **适用**：园艺、茶叶、自然产品、可持续发展
- **推荐macrostructure**：12·Letter、08·Photographic
- **品牌人格映射**：温暖朋友、环保倡导者

### 5. Brutal
- **风格**：先锋/反设计。覆盖图片+全出血+溢出大按钮+横向扫过入场。
- **配色**：高对比+bold accent+黑色背景
- **字体**：Bold sans display + utilitarian body
- **适用**：先锋设计、街头品牌、激进产品、创意agency
- **推荐macrostructure**：07·Manifesto、03·Marquee Hero
- **品牌人格映射**：叛逆先锋、活力创作者

### 6. Coral
- **风格**：海洋/清新。居中+单栏+外边距图片+fade-up。
- **配色**：蓝绿色系+白色背景+soft accent
- **字体**：Clean sans display + readable body
- **适用**：海洋产品、清新品牌、SPA、旅游
- **推荐macrostructure**：08·Photographic、12·Letter
- **品牌人格映射**：温暖朋友、健康顾问

### 7. Garden
- **风格**：园艺/教育。悬停+侧注+无动效+无按钮。
- **配色**：暖中性+绿色accent+paper background
- **字体**：Serif display + serif body（学术感）
- **适用**：教育、书籍、知识产品、学术
- **推荐macrostructure**：02·Long Document、17·Type Specimen
- **品牌人格映射**：教育品牌、权威专家

### 8. Manifesto
- **风格**：宣言/激进。重叠图片+全出血+横向扫过入场。
- **配色**：单一bold accent+黑/白背景
- **字体**：Bold display（可能是serif）+ minimal body
- **适用**：政治活动、激进品牌、社会运动、宣言页
- **推荐macrostructure**：07·Manifesto、03·Marquee Hero
- **品牌人格映射**：叛逆先锋、活动发起者

### 9. Midnight
- **风格**：夜间/神秘。编号显示+单栏+打字机入场。
- **配色**：深蓝/黑色背景+单一light accent
- **字体**：Mono display + mono body（terminal感）
- **适用**：夜间产品、神秘品牌、终端工具、CLI
- **推荐macrostructure**：06·Conversational FAQ、02·Long Document
- **品牌人格映射**：极客工程师、神秘创作者

### 10. Newsprint
- **风格**：报纸/资讯。底部对齐+多栏对齐+双线分隔+无入场。
- **配色**：纸白背景+black ink+单一accent
- **字体**：Serif display + serif body（报纸感）
- **适用**：新闻、杂志、资讯平台、内容聚合
- **推荐macrostructure**：02·Long Document、11·Catalogue
- **品牌人格映射**：权威专家、信息枢纽

### 11. Editorial
- **风格**：杂志/专题。悬停+两栏不对称+细线分隔。
- **配色**：中性+单一accent+high contrast
- **字体**：Distinctive serif display + refined body
- **适用**：杂志、专题报道、深度内容
- **推荐macrostructure**：02·Long Document、09·Quote-Led
- **品牌人格映射**：优雅艺术家、权威专家

### 12. Riso
- **风格**：印刷/复古。居中+单栏+无动效+无按钮。
- **配色**：limited palette（2-3色）+ paper texture
- **字体**：Retro display + clean body
- **适用**：复古品牌、独立出版、印刷品、手工感
- **推荐macrostructure**：11·Catalogue、17·Type Specimen
- **品牌人格映射**：活力创作者、手工艺人

### 13. Specimen
- **风格**：印刷体/编辑。左边距编号+巨大衬线+不对称span+细线+typographic CTA。
- **配色**：纸白+black ink+单一accent
- **字体**：Geometric serif display + serif body
- **适用**：**仅当用户明确要求编辑/印刷体风格时**
- **推荐macrostructure**：10·Specimen
- **品牌人格映射**：优雅艺术家、字体铸造师
- **禁止**：在SaaS/开发者工具/电商页默认使用

### 14. Sport
- **风格**：体育/活力。编号显示+不对称+溢出大按钮+横向扫过。
- **配色**：bold accent+dark background+high energy
- **字体**：Bold condensed sans display + strong body
- **适用**：体育品牌、活力产品、运动装备

- **品牌人格映射**：活力创作者、运动员

- **配色**：中性+单一accent+high contrast
- **字体**：Clean sans display + clean body
- **适用**：创意工作室、设计agency、作品集
- **推荐macrostructure**：15·Split Studio、18·Portfolio Grid
- **品牌人格映射**：优雅艺术家、创意导演

### 16. Tally
- **风格**：简约SaaS。居中+单栏+负间距+fade-up。
- **配色**：高对比中性+单一accent
- **字体**：Geometric sans display + clean body
- **适用**：SaaS产品、B2B工具、简约品牌
- **推荐macrostructure**：01·Bento Grid、05·Workbench
- **品牌人格映射**：数据驱动、权威专家

- **适用**：旅游、酒店、餐厅、探索品牌

### 18. NAJM

- **品牌人格映射**：优雅艺术家、潮流引领者

### 19. Hyperlane
- **风格**：开发者基础设施。
- **配色**：Dark mode+tech accent
- **字体**：Mono display + clean body
- **适用**：开发者工具、基础设施、API平台
- **推荐macrostructure**：05·Workbench、21·Component Playground
- **品牌人格映射**：极客工程师、技术权威

### 20. Custom
- **风格**：超出20种主题时的定制主题。
- **触发条件**：用户指定品牌色/多属性vibe/明确要求custom
- **流程**：见 references/custom-theme.md
- **适用**：特殊创意需求

## 主题选择规则

1. **根据brief能量匹配主题** — 使用路由表选3种（跨类别）
2. **检查代码库** — 搜索 `/* theme: <name> */` stamp，排除已用的
3. **默认从1-10选** — 这些覆盖80%需求
4. **声明选择** — 在CSS顶部添加stamp：`/* theme: <name> */`
5. **若用户选择custom** — 进入custom-theme.md流程
