# 57 字体配对参考手册

> 按风格分类，每个配对包含标题字体、正文字体、适用场景和配对理由。
> 所有字体均来自 Google Fonts，提供备选字体以应对加载失败场景。

## 附录：字体配对使用指南

### 配对原则
1. **对比与协调**: 标题与正文应有足够对比（衬线vs无衬线、展示vs功能），但在x字高和笔画风格上保持协调
2. **字重平衡**: 标题使用 Bold/Black (700-900)，正文使用 Regular/Medium (400-500)
3. **字号层次**: 标题与正文的字号比建议 1.5:1 至 2.5:1
4. **行高设置**: 正文行高 1.5-1.75，标题行高 1.1-1.3

### 字体加载优化
```html
<!-- 推荐的 Google Fonts 加载方式 -->
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&family=Playfair+Display:wght@700&display=swap" rel="stylesheet">
```

### CSS 变量设置模板
```css
:root {
  --font-heading: 'Playfair Display', 'Cormorant Garamond', serif;
  --font-body: 'Lato', 'Source Sans Pro', sans-serif;
  --font-mono: 'JetBrains Mono', 'Fira Code', monospace;
  
  --font-weight-heading: 700;
  --font-weight-body: 400;
  --font-weight-body-bold: 600;
  
  --line-height-heading: 1.2;
  --line-height-body: 1.6;
  
  --font-size-base: 16px;
  --font-size-sm: 0.875rem;
  --font-size-lg: 1.125rem;
  --font-size-xl: 1.25rem;
  --font-size-2xl: 1.5rem;
  --font-size-3xl: 1.875rem;
  --font-size-4xl: 2.25rem;
}
```

### 备选字体策略
- 每个配对都提供备选字体，当主字体加载失败时自动降级
- 建议在 `font-family` 中按优先级排列：`'主字体', '备选字体', 通用类别`
- 通用类别：serif / sans-serif / monospace / cursive / fantasy

### 中文字体补充
中文项目建议额外配置中文字体：
```css
:root {
  --font-heading-cn: 'Noto Serif SC', 'Source Han Serif SC', serif;
  --font-body-cn: 'Noto Sans SC', 'Source Han Sans SC', sans-serif;
}

/* 中英混排 */
font-family: var(--font-heading), var(--font-heading-cn), serif;
```
