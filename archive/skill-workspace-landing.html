核心创新

Darwin 9 维度评估体系

科学的量化评估系统，从多个维度全面评估 Skill 质量。

  • 触发准确性 - 评估 Skill 是否能正确识别用户意图
  • 输出质量 - 评估生成内容的质量和完整性
  • 工作流程 - 评估流程的合理性和完整性
  • 可访问性 - 评估 Skill 的易用性和可理解性
  • 安全性 - 评估是否存在安全风险
  • 性能 - 评估响应速度和资源消耗
  • 可维护性 - 评估代码结构和文档质量
  • 兼容性 - 评估跨平台和跨 Agent 兼容性
  • 创新性 - 评估解决方案的创新程度
质量保障

棘轮优化机制

确保 Skill 质量只升不降的优化策略。

  • 每轮优化后必须通过量化评估
  • 评分低于上一轮时自动回滚
  • 连续 2 轮改进不足时自动停止
  • 优化后文件大小受控，避免膨胀
  • 全程可追溯的优化历史记录
评估创新

多评委独立审查

避免 LLM 自评偏差的创新评估机制。

  • 每轮启动至少 2 个独立评委 agent
  • 评委不复用，确保评估独立性
  • 需要至少 2 个评委共识才有效
  • 子 agent 不可用时自动降级处理
  • 评估过程透明可追溯
风险防控

反例黑名单

识别和避免常见的 Skill 开发反模式。

  • 同 context 自评自改 - 避免自我欺骗
  • git reset --hard 当回滚 - 避免数据丢失
  • 为凑分增冗余 - 避免无效优化
  • 跳过 test-prompts 直接评分 - 确保评估准确
  • 轮内改多个维度 - 避免混乱优化
  • 静默跳过异常 - 确保问题可见
解决的问题

告别 Skill 管理痛点

针对开发者在 Skill 管理中遇到的常见问题，提供一站式解决方案

重复造轮子

不知道是否已有现成 Skill，花费大量时间开发已存在的功能。Skill Workspace 通过多源搜索帮你快速找到现有方案。

安全隐患

从网上下载的 Skill 可能包含恶意代码或安全漏洞。4 步安全审查协议确保每个 Skill 都经过严格验证。

质量参差不齐

缺乏统一的质量评估标准，难以判断 Skill 的好坏。Darwin 9 维度评估体系提供科学的量化评估。

碎片化管理

Agent 兼容性

工作流程

完整的生命周期管理

从发现到退役，每一步都有清晰的流程和质量保障

1

环境检查

检查基础依赖、网络连通性、搜索增强 Skill，确保执行环境正常。缺失依赖自动提示并提供安装方案。

2

智能搜索

多源搜索策略，从 SkillsMP、Skills.sh、CocoLoop、GitHub 等平台查找现有 Skill，避免重复造轮子。

3

安全审查

4 步审查协议：元数据检查、权限范围分析、内容扫描、Typosquat 检测，确保安全可靠。

4

开发/安装

从零开发或下载安装，深度需求挖掘，分阶段开发，循环审查，确保质量达标。

5

质量评估

Darwin 9 维度评估，多评委独立审查，量化评估 Skill 质量，确保达到标准。

6

优化改进

棘轮优化机制，持续改进质量，多轮优化直到达标，确保质量只升不降。

7

部署上线

部署到全局目录，验证部署结果，Agent CLI 测试，确保全局可用。

8

持续管理

版本更新、批量更新、安全卸载、合并整合，持续管理 Skill 生命周期。
